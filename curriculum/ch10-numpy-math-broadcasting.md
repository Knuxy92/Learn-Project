# บทที่ 10: คำนวณบน array และ broadcasting

## ทบทวน

บทที่แล้วเราเรียนสร้าง array (อาร์เรย์) ด้วย `np.array` ดูขนาดด้วย `shape` ดูชนิดด้วย `dtype` และเลือกข้อมูลด้วย index กับ slice

บทนี้ต่อยอดจากการสร้าง array ไปสู่การคำนวณทั้งชุดในครั้งเดียว ซึ่งเป็นเหตุผลหลักที่เราเลือก NumPy แทนลิสต์ธรรมดา

## คำนวณทั้ง array ในครั้งเดียว

การคำนวณแบบเวกเตอร์ (vectorized computation) คือการเขียนนิพจน์เดียวแล้วให้ NumPy ลงมือกับสมาชิกทุกตัวพร้อมกัน

ในลิสต์ธรรมดาเราต้องเขียนลูปหรือตัวสร้างลิสต์ (list comprehension) เพื่อคูณทีละคู่ แต่ array ทำได้ทันทีด้วยเครื่องหมายคณิตศาสตร์ปกติ

เรื่องนี้สำคัญกับงานทำความสะอาดข้อมูลเพราะข้อมูลจริงมีเป็นแสนแถว การเขียนลูปทีละแถวช้าและอ่านยาก การคำนวณทั้งคอลัมน์ในครั้งเดียวเร็วกว่าและโค้ดสั้นกว่า

```python
import numpy as np

prices = np.array([450.0, 300.0, 1200.0, 89.0])
quantities = np.array([2, 5, 1, 10])

line_totals = prices * quantities
print("ยอดต่อบรรทัด", line_totals)
```

ผลลัพธ์

```txt
ยอดต่อบรรทัด [ 900. 1500. 1200.  890.]
```

คูณ array สองตัวที่ขนาดเท่ากันจะคูณทีละตำแหน่ง ไม่ใช่คูณแบบเมทริกซ์

## ตัวดำเนินการที่ใช้ได้

เครื่องหมายคณิตศาสตร์ทุกตัวทำงานกับ array ทั้งชุด

| เครื่องหมาย | ความหมาย | ตัวอย่าง |
|---|---|---|
| `+` | บวก | `prices + 10` |
| `-` | ลบ | `prices - 50` |
| `*` | คูณทีละตำแหน่ง | `prices * quantities` |
| `/` | หาร | `counts / 2` |
| `//` | หารปัดลง | `counts // 2` |
| `**` | ยกกำลัง | `counts ** 2` |
| `%` | เศษจากการหาร | `counts % 2` |

```python
with_vat = line_totals * 1.07
print("รวมภาษีมูลค่าเพิ่ม", with_vat)

discounted = line_totals - 50
print("หักส่วนลดคนละห้าสิบ", discounted)
```

ผลลัพธ์

```txt
รวมภาษีมูลค่าเพิ่ม [ 963.  1605.  1284.   952.3]
หักส่วนลดคนละห้าสิบ [ 850. 1450. 1150.  840.]
```

การบวกหรือลบค่าคงที่หนึ่งค่ากับ array ทั้งชุดคือการกระจายค่าแบบง่ายที่สุด

## ชนิดของผลลัพธ์เปลี่ยนได้

ผลลัพธ์มีชนิดตามข้อมูลที่ใส่เข้าไป ถ้าหารด้วย `/` ผลลัพธ์เป็นทศนิยมเสมอ แม้ตัวตั้งกับตัวหารจะเป็นจำนวนเต็ม

```python
counts = np.array([1, 2, 3])
print("หารด้วยสอง", counts / 2)
print("ชนิดหลังหาร", (counts / 2).dtype)
print("หารเอาเฉพาะจำนวนเต็ม", counts // 2)
```

ผลลัพธ์

```txt
หารด้วยสอง [0.5 1.  1.5]
ชนิดหลังหาร float64
หารเอาเฉพาะจำนวนเต็ม [0 1 1]
```

เรื่องนี้สำคัญเพราะราคาที่มีทศนิยมจะทำให้ยอดรวมกลายเป็นทศนิยมทั้งคอลัมน์ เราไม่ต้องแปลงชนิดเอง

## การกระจายค่า (broadcasting)

การกระจายค่า (broadcasting) คือกฎที่ NumPy ใช้จับคู่ array ที่ขนาดไม่เท่ากันให้คำนวณกันได้

NumPy เทียบขนาดจากมิติขวาสุดไล่ไปทางซ้าย ถ้าขนาดของมิติใดเท่ากันหรือมีด้านหนึ่งเป็นหนึ่ง จะยืดด้านที่เล็กกว่าให้เท่ากับอีกด้าน

ต้องรู้เรื่องนี้เพราะตารางจริงมักมีราคาต่อหน่วยเป็นคอลัมน์เดียว แต่มีหลายแถว เราอยากคูณราคาชุดเดียวกับทุกแถวพร้อมกัน

```python
quantities = np.array(
    [
        [2, 1, 3],
        [4, 0, 2],
    ]
)
prices = np.array([450.0, 300.0, 1200.0])

print("ขนาดของตาราง", quantities.shape)
print("ขนาดของราคา", prices.shape)
print(quantities * prices)
```

ผลลัพธ์

```txt
ขนาดของตาราง (2, 3)
ขนาดของราคา (3,)
[[ 900.  300. 3600.]
 [1800.    0. 2400.]]
```

array ราคาขนาด `(3,)` ถูกยืดเป็น `(2, 3)` โดยใช้ค่าเดิมซ้ำทุกแถว ผลคือแต่ละแถวคูณด้วยราคาชุดเดียวกัน

## กระจายค่าจากแถวเดียว

อีกทิศทางที่ใช้บ่อยคือคำนวณค่าสรุปของแต่ละแถว แล้วลบออกจากทุกช่องในแถวนั้น

การใส่ `keepdims=True` ทำให้ผลลัพธ์ยังคงสองมิติ ขนาดจึงจับคู่กับ array เดิมได้

```python
rows = np.array([[1.0, 2.0, 3.0], [10.0, 20.0, 30.0]])
print(rows - rows.mean(axis=1, keepdims=True))
```

ผลลัพธ์

```txt
[[ -1.   0.   1.]
 [-10.   0.  10.]]
```

ถ้าไม่ใส่ `keepdims=True` ผลลัพธ์จะเป็นขนาด `(2,)` ซึ่งกระจายเข้ากับ `(2, 3)` ไม่ได้

## ปรับค่าให้อยู่ในช่วงเดียวกัน

สูตรปรับช่วง (normalization) ที่ใช้บ่อยคือลบค่าต่ำสุดออกแล้วหารด้วยช่วงกว้าง

```python
scores = np.array([3.0, 5.0, 7.0, 9.0])
lowest = scores.min()
highest = scores.max()
print("ช่วงคะแนน", lowest, highest)
print("ปรับให้อยู่ระหว่างศูนย์กับหนึ่ง", (scores - lowest) / (highest - lowest))
```

ผลลัพธ์

```txt
ช่วงคะแนน 3.0 9.0
ปรับให้อยู่ระหว่างศูนย์กับหนึ่ง [0.         0.33333333 0.66666667 1.        ]
```

ใช้เมื่ออยากเทียบข้อมูลคนละหน่วย เช่น ราคากับจำนวนชิ้น ให้อยู่ในมาตราเดียวกันก่อน

ข้อควรระวังคือถ้าค่าทุกตัวเท่ากัน ช่วงกว้างจะเป็นศูนย์และการหารจะพัง ต้องเช็กก่อนเสมอ

## เมื่อขนาดเข้ากันไม่ได้

ถ้าขนาดของมิติขวาสุดไม่เท่ากันและไม่มีด้านใดเป็นหนึ่ง NumPy จะไม่เดาให้ แต่โยนข้อผิดพลาดทันที

```python
try:
    quantities * np.array([1.0, 2.0])
except ValueError:
    print("ขนาดไม่เข้ากันจึงล้มเหลว")
```

ผลลัพธ์

```txt
ขนาดไม่เข้ากันจึงล้มเหลว
```

อ่านข้อความนี้ได้ว่า ขนาด `(2, 3)` กับ `(2,)` จับคู่กันไม่ได้ เพราะมิติขวาสุดคือ 3 กับ 2

## เลือกค่าด้วย np.where

`np.where` เลือกค่าจากสองชุดตามเงื่อนไข คล้าย `if` แต่ทำกับทุกสมาชิกพร้อมกัน

เรื่องนี้สำคัญเพราะข้อมูลดิบมีค่าที่เป็นไปไม่ได้ เช่น จำนวนติดลบ หรือราคาเป็นศูนย์ เราต้องแก้ก่อนนำไปคำนวณ

```python
overdue_days = np.array([3, -2, 5, -7])
print("วันคงค้างก่อนแก้", overdue_days)
print("วันคงค้างหลังแก้ค่าติดลบ", np.where(overdue_days < 0, 0, overdue_days))
```

ผลลัพธ์

```txt
วันคงค้างก่อนแก้ [ 3 -2  5 -7]
วันคงค้างหลังแก้ค่าติดลบ [3 0 5 0]
```

รูปแบบคือ `np.where(เงื่อนไข, ค่าถ้าจริง, ค่าถ้าเท็จ)` โดยคืน array ใหม่ ไม่แก้ของเดิม

## สรุป

| ต้องการ | วิธีเขียน |
|---|---|
| บวกค่าคงที่ทั้ง array | `values + 10` |
| คูณสอง array ขนาดเท่ากัน | `a * b` |
| คูณราคาชุดเดียวกับทุกแถว | `table * prices` |
| ลบค่าเฉลี่ยของแต่ละแถว | `table - table.mean(axis=1, keepdims=True)` |
| ปรับช่วงเป็นศูนย์ถึงหนึ่ง | `(x - x.min()) / (x.max() - x.min())` |
| แทนค่าติดลบด้วยศูนย์ | `np.where(x < 0, 0, x)` |

หลักจำง่ายสามข้อ

- array สองตัวขนาดเท่ากันคำนวณทีละตำแหน่ง
- array ที่มีมิติเป็นหนึ่งจะถูกยืดให้เท่าอีกฝ่าย
- ถ้าขนาดจับคู่ไม่ได้ NumPy จะโยน `ValueError` ไม่เดาให้

# บทที่ 11: เลือกข้อมูลและสรุปค่าด้วย NumPy

## ทบทวน

บทที่แล้วเราเรียนคำนวณทั้ง array ในครั้งเดียว และใช้การกระจายค่า (broadcasting) ให้ array ขนาดต่างกันจับคู่กันได้

บทที่ 9 เราเรียนสร้างมาสก์ด้วยการเปรียบเทียบ แล้วเอามาสก์ไปใส่ในวงเล็บเหลี่ยมเพื่อเลือกแถว

บทนี้ต่อยอดจากตรงนั้นด้วยงานที่ต้องทำจริงบนข้อมูลสกปรก คือทำความสะอาดข้อความก่อนสร้างมาสก์ รวมเงื่อนไขให้ถูก แล้วสรุปค่าสถิติทั้งคอลัมน์

## ทำความสะอาดข้อความก่อนสร้างมาสก์

ข้อมูลจริงมักมีตัวพิมพ์และช่องว่างปนกัน เช่น `paid`, `PAID`, ` Paid ` ซึ่งเปรียบเทียบตรง ๆ กับ `"paid"` จะพลาดไปหลายแถว

`np.strings` มีฟังก์ชันข้อความที่ทำงานกับทั้ง array พร้อมกัน ใช้ `strip` ตัดช่องว่างหัวท้าย แล้ว `lower` ทำเป็นตัวพิมพ์เล็ก

ทำแบบนี้ทุกครั้งก่อนสร้างมาสก์ ไม่อย่างนั้นยอดรวมจะขาดแถวที่พิมพ์ผิดรูปแบบไปเงียบ ๆ

```python
import numpy as np

statuses = np.array(["paid", " PAID ", "pending", "Paid", "cancelled", "paid"])

cleaned = np.strings.lower(np.strings.strip(statuses))
print("สถานะหลังทำความสะอาด", cleaned)

paid_mask = cleaned == "paid"
print("มาสก์ของออเดอร์ที่จ่ายแล้ว", paid_mask)
```

ผลลัพธ์

```txt
สถานะหลังทำความสะอาด ['paid' 'paid' 'pending' 'paid' 'cancelled' 'paid']
มาสก์ของออเดอร์ที่จ่ายแล้ว [ True  True False  True False  True]
```

## รวมสองเงื่อนไขเข้าด้วยกัน

บทที่ 9 สอนว่าใช้ `&` กับ `|` แทน `and` กับ `or` บทนี้เพิ่มจุดที่พลาดบ่อยคือลำดับความสำคัญของเครื่องหมาย

`&` มีลำดับความสำคัญสูงกว่าตัวเปรียบเทียบ ถ้าไม่ใส่วงเล็บ Python จะอ่านนิพจน์ผิดความหมาย

ใส่่วงเล็บรอบการเปรียบเทียบทุกอันแล้วปัญหานี้หายไป

```python
revenue = np.array([900.0, 1500.0, 1200.0, 890.0, 4200.0, 300.0])

big_paid = paid_mask & (revenue >= 1000)
print("จ่ายแล้วและยอดตั้งแต่หนึ่งพัน", revenue[big_paid])

paid_or_big = paid_mask | (revenue >= 2000)
print("จ่ายแล้วหรือยอดตั้งแต่สองพัน", revenue[paid_or_big])
```

ผลลัพธ์

```txt
จ่ายแล้วและยอดตั้งแต่หนึ่งพัน [1500.]
จ่ายแล้วหรือยอดตั้งแต่สองพัน [ 900. 1500.  890. 4200.  300.]
```

## เลือกค่าด้วย np.where

`np.where` คืน array ใหม่ที่เลือกค่าจากสองชุดตามมาสก์ เหมาะกับการสร้างคอลัมน์ป้ายกำกับ

ใช้เมื่ออยากได้ข้อความอ่านง่ายแทนค่าจริง เช่น เปลี่ยนสถานะเป็นคำไทย หรือแปลงค่าที่ผิดเงื่อนไขเป็นข้อความเตือน

```python
labels = np.where(paid_mask, "ชำระแล้ว", "รอตรวจ")
print("ป้ายกำกับ", labels)
```

ผลลัพธ์

```txt
ป้ายกำกับ ['ชำระแล้ว' 'ชำระแล้ว' 'รอตรวจ' 'ชำระแล้ว' 'รอตรวจ' 'ชำระแล้ว']
```

## ค่าสรุปพื้นฐาน

array มีเมธอดสรุปในตัว ทั้งหมดคืนค่าเดียว ไม่ต้องเขียนลูป

| เมธอด | ความหมาย |
|---|---|
| `mean()` | ค่าเฉลี่ย |
| `median()` | มัธยฐาน |
| `min()` | ค่าน้อยสุด |
| `max()` | ค่ามากสุด |
| `sum()` | ผลรวม |
| `std()` | ส่วนเบี่ยงเบนมาตรฐาน |

```python
print("ค่าเฉลี่ย", revenue.mean())
print("มัธยฐาน", np.median(revenue))
print("ค่าน้อยสุด", revenue.min())
print("ค่ามากสุด", revenue.max())
print("ผลรวม", revenue.sum())
```

ผลลัพธ์

```txt
ค่าเฉลี่ย 1498.3333333333333
มัธยฐาน 1050.0
ค่าน้อยสุด 300.0
ค่ามากสุด 4200.0
ผลรวม 8990.0
```

ค่าเฉลี่ยกับมัธยฐานต่างกันมากบอกว่ามีค่าสุดโต่งดึงค่าเฉลี่ยขึ้น ต้องดูทั้งคู่ ไม่ดูตัวใดตัวหนึ่ง

## ตำแหน่งของค่าสุดขั้ว

`argmax` กับ `argmin` คืนตำแหน่ง ไม่ใช่ค่า ใช้เมื่ออยากรู้ว่าแถวไหนมียอดสูงสุด

```python
print("ตำแหน่งของยอดสูงสุด", revenue.argmax())
print("ยอดที่ตำแหน่งนั้น", revenue[revenue.argmax()])
```

ผลลัพธ์

```txt
ตำแหน่งของยอดสูงสุด 4
ยอดที่ตำแหน่งนั้น 4200.0
```

ตำแหน่งนี้นับจากศูนย์ และใช้ดึงข้อมูลแถวนั้นจาก array อื่นที่มีขนาดเท่ากันได้

## สรุปรายมิติด้วย axis

array สองมิติสรุปได้สองทิศทาง ค่า `axis=1` รวมตามแถว ส่วน `axis=0` รวมตามคอลัมน์

```python
by_month = np.array(
    [
        [900.0, 1500.0, 1200.0],
        [890.0, 4200.0, 300.0],
    ]
)
print("ยอดรวมของแต่ละเดือน", by_month.sum(axis=1))
print("ยอดรวมของแต่ละช่อง", by_month.sum(axis=0))
```

ผลลัพธ์

```txt
ยอดรวมของแต่ละเดือน [3600. 5390.]
ยอดรวมของแต่ละช่อง [1790. 5700. 1500.]
```

จำง่าย ๆ ว่า `axis=1` คือย่อแต่ละแถวให้เหลือค่าเดียว ส่วน `axis=0` คือย่อแต่ละคอลัมน์

## ค่าหายไปกับ nan

ถ้าในคอลัมน์มีค่าหายไปซึ่ง NumPy แทนด้วย `nan` ค่าเฉลี่ยทั้งคอลัมน์จะกลายเป็น `nan` ทันที

```python
with_missing = np.array([10.0, np.nan, 30.0])
print("ค่าเฉลี่ยเมื่อมีค่าหายไป", with_missing.mean())
print("ค่าเฉลี่ยที่ข้ามค่าหายไป", np.nanmean(with_missing))
print("ผลรวมที่ข้ามค่าหายไป", np.nansum(with_missing))
```

ผลลัพธ์

```txt
ค่าเฉลี่ยเมื่อมีค่าหายไป nan
ค่าเฉลี่ยที่ข้ามค่าหายไป 20.0
ผลรวมที่ข้ามค่าหายไป 40.0
```

ฟังก์ชันที่ขึ้นต้นด้วย `nan` จะข้ามค่าหายไป แต่ต้องเลือกให้ตรงกับธุรกิจ เพราะการข้ามค่าหายไปทำให้ตัวหารน้อยลง

## สรุป

| ต้องการ | วิธีเขียน |
|---|---|
| ทำความสะอาดข้อความทั้ง array | `np.strings.lower(np.strings.strip(values))` |
| สร้างมาสก์จากเงื่อนไข | `values > 1000` |
| เลือกเฉพาะแถวที่ตรงเงื่อนไข | `values[mask]` |
| เลือกแถวที่ไม่ตรงเงื่อนไข | `values[~mask]` |
| รวมสองเงื่อนไข | `mask_a & mask_b` |
| รวมเงื่อนไขแบบหรือ | `mask_a \| mask_b` |
| นับแถวที่ตรงเงื่อนไข | `mask.sum()` |
| สรุปค่าสถิติ | `values.mean()` กับ `np.median(values)` |
| ตำแหน่งค่าสูงสุด | `values.argmax()` |
| รวมตามแถวหรือคอลัมน์ | `values.sum(axis=1)` หรือ `axis=0` |
| ข้ามค่าหายไป | `np.nanmean(values)` |

หลักจำง่ายสามข้อ

- ทำความสะอาดข้อความก่อนสร้างมาสก์ทุกครั้ง
- รวมเงื่อนไขต้องใช้ `&` กับ `|` และใส่วงเล็บทุกอัน
- ค่าเฉลี่ยที่ติด `nan` แปลว่ามีค่าหายไปปนอยู่ ให้เลือกใช้ฟังก์ชัน `nan` ให้ถูก

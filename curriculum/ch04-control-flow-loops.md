# บทที่ 4: การควบคุมทิศทางและลูป

## ทบทวน

สามบทแรกเราเขียนคำสั่งให้ทำงานจากบนลงล่าง แต่เมื่อมีข้อมูลหลายรายการ เรามักต้องตรวจแต่ละรายการและทำสิ่งต่างกันตามเงื่อนไข

บทนี้จะเรียนรู้การเลือกทำงานด้วย if และการทำงานซ้ำด้วยลูป

รันตัวอย่างด้วย CMD:

~~~cmd
python curriculum\ch04\if-else-example.py
python curriculum\ch04\loop-example.py
~~~

## 1. if เลือกทำงานตามเงื่อนไข

if ใช้ตรวจว่าเงื่อนไขเป็นจริงหรือไม่ ถ้าเป็นจริง Python จะทำคำสั่งที่เยื้องอยู่ข้างใน

~~~python
total = 450

if total >= 1000:
    print("ส่งฟรี")
~~~

ตัวอย่างนี้ไม่มีข้อความแสดงผล เพราะ 450 ไม่ถึง 1000

ลองเปลี่ยนค่า total เป็น 1200 แล้วรันอีกครั้ง จะเห็นคำว่า ส่งฟรี

**การเยื้องบรรทัดสำคัญมาก** คำสั่งที่อยู่ใน if ต้องเยื้องเข้าไป โดยปกติใช้ 4 ช่องว่าง

## 2. if กับ else

else ใช้กำหนดสิ่งที่ต้องทำเมื่อเงื่อนไขใน if เป็นเท็จ

~~~python
total = 450

if total >= 1000:
    print("ส่งฟรี")
else:
    print("ค่าส่ง 50 บาท")
~~~

ผลลัพธ์:

~~~txt
ค่าส่ง 50 บาท
~~~

## 3. if, elif และ else

เมื่อมีหลายช่วงเงื่อนไข ใช้ elif เพิ่มทางเลือกได้

~~~python
total = 1200

if total < 500:
    print("ยอดเล็ก")
elif total < 2000:
    print("ยอดปานกลาง")
else:
    print("ยอดใหญ่")
~~~

ผลลัพธ์:

~~~txt
ยอดปานกลาง
~~~

Python ตรวจจากบนลงล่าง และทำเฉพาะบล็อกแรกที่เงื่อนไขเป็นจริง

## 4. รวมหลายเงื่อนไขด้วย and และ or

and หมายถึงทุกเงื่อนไขต้องจริง ส่วน or หมายถึงมีอย่างน้อยหนึ่งเงื่อนไขจริง

~~~python
status = "pending"
total = 2600

if status == "pending" and total >= 2000:
    print("ต้องตรวจสอบรายการนี้")

if status == "paid" or status == "pending":
    print("เป็นสถานะที่ระบบรู้จัก")
~~~

ผลลัพธ์:

~~~txt
ต้องตรวจสอบรายการนี้
เป็นสถานะที่ระบบรู้จัก
~~~

## 5. รู้จัก list ก่อนใช้ for

ในงานข้อมูล เรามักมีค่าหลายรายการที่ต้องจัดการร่วมกัน เราสามารถเก็บค่าเหล่านั้นไว้ใน list (ลิสต์) ได้

~~~python
prices = [120, 250, 300]

print(prices)
print(prices[0])
print(prices[1])
~~~

ผลลัพธ์:

~~~txt
[120, 250, 300]
120
250
~~~

ค่าภายใน list คั่นด้วยเครื่องหมายจุลภาค และตำแหน่งแรกเริ่มนับจาก 0

บทนี้จะใช้ list ในระดับพื้นฐานเพื่อฝึกวนดูข้อมูล ส่วนการเพิ่ม ลบ แก้ไข และใช้ list อย่างละเอียดจะอยู่ในบทที่ 6

## 6. for วนดูข้อมูลทีละรายการ

for ใช้ทำคำสั่งเดิมซ้ำกับสมาชิกแต่ละตัวใน list

~~~python
prices = [120, 250, 300]

for price in prices:
    print(price)
~~~

ผลลัพธ์:

~~~txt
120
250
300
~~~

อ่านว่า นำสมาชิกแต่ละตัวใน prices มาเก็บไว้ในตัวแปร price ทีละตัว แล้วทำคำสั่งที่อยู่ข้างใน

## 7. ใช้ if ภายใน for

เราสามารถตรวจแต่ละรายการระหว่างที่วนลูปได้

~~~python
prices = [120, 250, 300, 1500]

for price in prices:
    if price >= 500:
        print(f"ราคาสูง: {price}")
~~~

ผลลัพธ์:

~~~txt
ราคาสูง: 1500
~~~

นี่เป็นรูปแบบพื้นฐานของการตรวจข้อมูลหลายรายการ: วนดูทีละค่า แล้วใช้เงื่อนไขตัดสินใจ

## 8. ตัวสะสม

ตัวสะสมคือ ตัวแปรที่ใช้เก็บผลรวมระหว่างวนลูป

~~~python
prices = [120, 250, 300]
total = 0

for price in prices:
    total = total + price

print(f"ยอดรวม: {total}")
~~~

ผลลัพธ์:

~~~txt
ยอดรวม: 670
~~~

ต้องกำหนดค่าเริ่มต้นของ total ก่อนเริ่มลูป และต้องวางไว้นอกลูป ไม่เช่นนั้นค่าจะถูกเริ่มใหม่ทุกครั้ง

เขียนย่อได้ด้วย +=:

~~~python
total = 0
total += 120
total += 250
print(total)
~~~

## 9. break และ continue

break ใช้ออกจากลูปทันทีเมื่อเจอสิ่งที่ต้องการ

~~~python
prices = [120, 250, 300, 1500]

for price in prices:
    if price >= 500:
        print(f"เจอราคาสูง: {price}")
        break
~~~

continue ใช้ข้ามรอบปัจจุบัน แล้วไปดูสมาชิกตัวถัดไป

~~~python
prices = [120, 250, 300, 1500]

for price in prices:
    if price < 200:
        continue
    print(price)
~~~

ผลลัพธ์:

~~~txt
250
300
1500
~~~

## 10. while วนตามเงื่อนไข

while ทำคำสั่งซ้ำตราบใดที่เงื่อนไขยังเป็นจริง

~~~python
remaining = 3

while remaining > 0:
    print(f"เหลืออีก {remaining} รอบ")
    remaining -= 1
~~~

ผลลัพธ์:

~~~txt
เหลืออีก 3 รอบ
เหลืออีก 2 รอบ
เหลืออีก 1 รอบ
~~~

ต้องมีคำสั่งที่ทำให้เงื่อนไขเปลี่ยนไป หากลืมลดค่า remaining ลูปอาจทำงานไม่จบ เรียกว่า infinite loop

หากลูปค้าง สามารถกด Ctrl+C ใน CMD เพื่อหยุดโปรแกรมได้

## สรุป

- if ใช้เลือกทำงานเมื่อเงื่อนไขเป็นจริง
- else ใช้กำหนดทางเลือกเมื่อเงื่อนไขเป็นเท็จ
- elif ใช้เพิ่มเงื่อนไขทางเลือก
- and และ or ใช้รวมเงื่อนไข
- list ใช้เก็บค่าหลายรายการ
- for ใช้วนดูสมาชิกทีละตัว
- break ใช้ออกจากลูป และ continue ใช้ข้ามรอบ
- while วนตราบใดที่เงื่อนไขยังเป็นจริง

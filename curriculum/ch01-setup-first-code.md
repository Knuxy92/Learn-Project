# บทที่ 1: ติดตั้ง Python และรันโค้ดแรก

บทนี้เริ่มจากศูนย์ เป้าหมายไม่ใช่เขียนโปรแกรมเก่งทันที แต่คือทำให้เปิด CMD เข้าโฟลเดอร์โปรเจกต์ เปิดไฟล์ Python และสั่งให้คอมพิวเตอร์ทำงานได้ด้วยตัวเอง

## 1. Python คืออะไร

Python คือภาษาโปรแกรม เราเขียนคำสั่งด้วยภาษาที่คนอ่านได้ แล้วให้โปรแกรม Python แปลคำสั่งเหล่านั้นเป็นการทำงานของคอมพิวเตอร์

หลักสูตรนี้ใช้ Python เพราะมีเครื่องมือสำหรับจัดการข้อมูล เช่น NumPy และ Pandas

## 2. เตรียมโปรแกรมที่ต้องใช้

หลักสูตรนี้ใช้ Windows 10/11 และ Command Prompt (CMD)

ติดตั้งโปรแกรมต่อไปนี้ก่อนเริ่ม:

1. **Python 3.11 ขึ้นไป** ดาวน์โหลดจาก https://www.python.org/downloads/windows/
2. **Git for Windows** ดาวน์โหลดจาก https://git-scm.com/download/win
3. **Visual Studio Code** หรือโปรแกรมแก้ไขโค้ดที่ถนัด

ตอนติดตั้ง Python ให้เลือก **Add python.exe to PATH** และติดตั้ง Python Launcher หากมีตัวเลือกนี้

PATH คือรายการตำแหน่งที่ Windows ใช้ค้นหาโปรแกรม เมื่อเลือกตัวเลือกนี้ CMD จะหาคำสั่ง Python เจอโดยไม่ต้องพิมพ์ตำแหน่งไฟล์เต็ม ส่วน Python Launcher เป็นตัวช่วยให้เรียก Python ด้วยคำสั่ง py

## 3. เปิด CMD

1. กดปุ่ม Windows บนคีย์บอร์ด
2. พิมพ์ cmd
3. กด Enter

หน้าต่างที่เปิดขึ้นมาคือ Command Prompt หรือ CMD เราจะพิมพ์คำสั่งลงในหน้าต่างนี้

ตรวจสอบว่า Python พร้อมใช้งานหรือยัง:

~~~cmd
py --version
~~~

ตัวอย่างผลลัพธ์:

~~~txt
Python 3.13.0
~~~

ตัวเลขเวอร์ชันอาจต่างกันได้ ขอให้เป็น 3.11 หรือใหม่กว่า คำสั่ง py คือ Python Launcher ที่ใช้เรียก Python ในเครื่อง

ถ้าขึ้นว่าไม่รู้จักคำสั่ง py ให้ตรวจว่าติดตั้ง Python Launcher แล้วหรือยัง และลองปิด CMD เปิดใหม่หลังติดตั้ง

## 4. เข้าโฟลเดอร์โปรเจกต์

ถ้า Clone โปรเจกต์ไว้บน Desktop ให้พิมพ์:

~~~cmd
cd /d "%USERPROFILE%\Desktop\Learn-Project"
~~~

คำสั่ง cd ใช้เปลี่ยนโฟลเดอร์ ส่วน /d ช่วยเปลี่ยนไดรฟ์ด้วยหากจำเป็น

ตรวจสอบว่าอยู่ในโฟลเดอร์ที่ถูกต้อง:

~~~cmd
dir
~~~

คำสั่ง dir แสดงรายชื่อไฟล์และโฟลเดอร์ ควรเห็น README.md, curriculum, exercises และโฟลเดอร์อื่นของโปรเจกต์

## 5. สร้างพื้นที่ติดตั้งไลบรารี

Virtual Environment คือพื้นที่แยกสำหรับติดตั้งไลบรารีของโปรเจกต์นี้ เพื่อไม่ให้ไลบรารีปะปนกับโปรเจกต์อื่น

สร้างพื้นที่นี้หนึ่งครั้ง:

~~~cmd
py -m venv .venv
~~~

เปิดใช้งาน:

~~~cmd
.venv\Scripts\activate.bat
~~~

ถ้าสำเร็จ จะเห็น (.venv) อยู่หน้าบรรทัดคำสั่ง

ติดตั้งไลบรารีที่หลักสูตรใช้:

~~~cmd
python -m pip install --upgrade pip
python -m pip install "numpy>=2.0,<3" "pandas>=3.0,<4" "pytest>=8.0,<10" "ruff>=0.6,<1"
~~~

เมื่อเปิด CMD หน้าต่างใหม่ ต้องเข้าโฟลเดอร์โปรเจกต์และเปิดใช้งานพื้นที่นี้อีกครั้งด้วยคำสั่ง activate

## 6. เขียนคำสั่งแรกด้วย print

เปิด Visual Studio Code แล้วเลือก File > Open Folder จากนั้นเลือกโฟลเดอร์ Learn-Project

ในแถบ Explorer ด้านซ้าย คลิกปุ่ม New File แล้วตั้งชื่อไฟล์ว่า hello.py ตรวจให้แน่ใจว่านามสกุลเป็น .py ไม่ใช่ .txt

ไฟล์ Python ลงท้ายด้วย .py เราจะเริ่มจากคำสั่ง print ซึ่งใช้แสดงข้อความออกทางหน้าจอ

~~~python
print("Hello Data")
~~~

พิมพ์โค้ดนี้ในไฟล์ hello.py แล้วกด Ctrl+S เพื่อบันทึก

กลับไปที่ CMD แล้วสั่ง:

~~~cmd
python hello.py
~~~

ผลลัพธ์ที่ควรเห็น:

~~~txt
Hello Data
~~~

ถ้าเห็นข้อความนี้ แปลว่าเราเขียนไฟล์ Python และสั่งให้ Python รันไฟล์ได้แล้ว

## 7. รู้จักตัวแปร

ตัวแปร (variable) คือชื่อที่ใช้เก็บค่าไว้เรียกใช้ภายหลัง

~~~python
student_name = "Student"
student_age = 17

print(student_name)
print(student_age)
~~~

ผลลัพธ์:

~~~txt
Student
17
~~~

บรรทัด student_name = "Student" หมายถึงเก็บข้อความ Student ไว้ภายใต้ชื่อ student_name ส่วน print ใช้แสดงค่าที่เก็บไว้

## 8. แสดงข้อความร่วมกับตัวแปร

f-string ช่วยแทรกค่าของตัวแปรลงในข้อความ โดยใส่ตัวอักษร f ไว้หน้าข้อความ และใส่ชื่อตัวแปรไว้ในวงเล็บปีกกา

~~~python
student_name = "Student"
student_age = 17

print(f"ชื่อ: {student_name}")
print(f"อายุ: {student_age} ปี")
~~~

ผลลัพธ์:

~~~txt
ชื่อ: Student
อายุ: 17 ปี
~~~

## 9. รันตัวอย่างของบทเรียน

ใน CMD ให้แน่ใจว่าอยู่ในโฟลเดอร์ Learn-Project และเปิดใช้งาน Virtual Environment แล้ว จากนั้นสั่ง:

~~~cmd
python curriculum\ch01\hello-world.py
~~~

ควรเห็นข้อความชื่อ อายุ และเป้าหมายของหลักสูตร

- curriculum/ เก็บบทเรียนและตัวอย่าง ไม่ต้องแก้ในช่วงทำโจทย์
- exercises/ เก็บไฟล์โจทย์ที่ผู้เรียนต้องแก้
- solutions/ เก็บคำตอบอ้างอิง ใช้สำหรับตรวจสอบ ไม่ควรเปิดดูก่อนลองทำ
- tests/ เก็บชุดทดสอบคำตอบ

## ถ้าเจอปัญหา

- py is not recognized: ติดตั้ง Python Launcher หรือแก้ PATH แล้วเปิด CMD ใหม่
- python is not recognized: ตรวจการตั้งค่า PATH ของ Python; สามารถลองใช้ py แทนได้
- can't open file: ตรวจว่า CMD อยู่ในโฟลเดอร์ Learn-Project ด้วยคำสั่ง dir
- No module named ...: ตรวจว่าเปิดใช้งาน .venv แล้วติดตั้งไลบรารีครบ

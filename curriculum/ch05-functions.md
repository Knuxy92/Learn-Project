# บทที่ 5: ฟังก์ชัน

## ทบทวน

ในบทก่อนเราเขียนคำสั่งให้ทำงานตามลำดับ ใช้ if เลือกทาง และใช้ลูปทำงานซ้ำ

เมื่อโปรแกรมเริ่มยาวขึ้น เราอาจต้องใช้ชุดคำสั่งเดิมหลายครั้ง ฟังก์ชันช่วยรวมคำสั่งเหล่านั้นไว้ในชื่อเดียว เพื่อเรียกใช้ซ้ำได้

## 1. ฟังก์ชันคืออะไร

ฟังก์ชัน (function) คือชุดคำสั่งที่เราตั้งชื่อไว้ แล้วเรียกให้ทำงานเมื่อจำเป็น

~~~python
def say_hello():
    print("สวัสดี")
    print("ยินดีต้อนรับสู่ Python")

say_hello()
~~~

ผลลัพธ์:

~~~txt
สวัสดี
ยินดีต้อนรับสู่ Python
~~~

ทำความเข้าใจทีละส่วน:

- def ใช้เริ่มประกาศฟังก์ชัน
- say_hello คือชื่อฟังก์ชัน
- วงเล็บ () คือส่วนที่รับข้อมูลเพิ่มเติมได้
- เครื่องหมาย : บอกว่าเนื้อหาของฟังก์ชันเริ่มต้นในบรรทัดถัดไป
- คำสั่งที่เยื้องอยู่ข้างในคือสิ่งที่ฟังก์ชันจะทำ
- say_hello() คือการเรียกให้ฟังก์ชันทำงาน

การประกาศฟังก์ชันยังไม่ทำให้คำสั่งข้างในทำงาน ต้องเรียกใช้ก่อน

## 2. พารามิเตอร์และอาร์กิวเมนต์

บางครั้งฟังก์ชันต้องรับข้อมูลเพื่อใช้คำนวณ

~~~python
def greet(name):
    print(f"สวัสดี {name}")

greet("Mali")
greet("Somchai")
~~~

ผลลัพธ์:

~~~txt
สวัสดี Mali
สวัสดี Somchai
~~~

name เรียกว่า parameter (พารามิเตอร์) เป็นชื่อที่เตรียมไว้รับข้อมูล ส่วน "Mali" และ "Somchai" คือ argument (อาร์กิวเมนต์) หรือค่าที่ส่งเข้ามาตอนเรียกใช้

## 3. ฟังก์ชันรับข้อมูลได้หลายค่า

~~~python
def show_customer(name, age):
    print(f"ชื่อลูกค้า: {name}")
    print(f"อายุ: {age}")

show_customer("Mali", 28)
~~~

ผลลัพธ์:

~~~txt
ชื่อลูกค้า: Mali
อายุ: 28
~~~

จำนวนและลำดับของค่าที่ส่งเข้าไปต้องตรงกับพารามิเตอร์ที่ฟังก์ชันกำหนดไว้

## 4. return ส่งผลลัพธ์กลับ

print ใช้แสดงผลบนหน้าจอ ส่วน return ใช้ส่งค่ากลับจากฟังก์ชันให้โค้ดส่วนอื่นนำไปใช้ต่อ

~~~python
def calculate_total(price, quantity):
    total = price * quantity
    return total

result = calculate_total(450, 3)
print(result)
print(result + 100)
~~~

ผลลัพธ์:

~~~txt
1350
1450
~~~

ถ้าฟังก์ชันมีแค่ print เราจะเห็นข้อความ แต่ไม่ได้รับค่ากลับมาเก็บไว้คำนวณต่อ

## 5. return ทำให้ฟังก์ชันจบ

เมื่อ Python เจอ return ฟังก์ชันจะส่งค่ากลับและจบการทำงานทันที

~~~python
def shipping_fee(total):
    if total >= 1000:
        return 0
    return 50

print(shipping_fee(1200))
print(shipping_fee(450))
~~~

ผลลัพธ์:

~~~txt
0
50
~~~

ถ้าเงื่อนไขแรกเป็นจริง ฟังก์ชันจะจบที่ return 0 และไม่ทำบรรทัดถัดไป

## 6. ค่าเริ่มต้นของพารามิเตอร์

เรากำหนดค่าเริ่มต้นให้พารามิเตอร์ได้ หากตอนเรียกไม่ได้ส่งค่านั้นมา Python จะใช้ค่าเริ่มต้น

~~~python
def greet(name, prefix="คุณ"):
    print(f"สวัสดี{prefix}{name}")

greet("Mali")
greet("Somchai", "คุณ")
~~~

ผลลัพธ์:

~~~txt
สวัสดีคุณMali
สวัสดีคุณSomchai
~~~

พารามิเตอร์ที่มีค่าเริ่มต้นควรอยู่หลังพารามิเตอร์ที่ไม่มีค่าเริ่มต้น

## 7. ส่งค่าด้วยชื่อพารามิเตอร์

เราสามารถระบุชื่อพารามิเตอร์ตอนเรียกฟังก์ชันได้

~~~python
def describe_order(price, quantity):
    print(f"ราคา {price} บาท จำนวน {quantity} ชิ้น")

describe_order(quantity=3, price=450)
~~~

ผลลัพธ์:

~~~txt
ราคา 450 บาท จำนวน 3 ชิ้น
~~~

การระบุชื่อช่วยให้เห็นชัดว่าค่าแต่ละตัวส่งไปให้พารามิเตอร์ใด

## 8. คำอธิบายชนิดข้อมูลของพารามิเตอร์ (type hints)

ในตัวอย่างบางแห่งอาจเห็นคำอธิบายชนิดข้อมูลอยู่ในวงเล็บของฟังก์ชัน หรือหลังเครื่องหมายลูกศร

~~~python
def calculate_total(price: float, quantity: int) -> float:
    return price * quantity
~~~

price: float หมายถึงคาดว่าจะรับตัวเลขทศนิยม, quantity: int หมายถึงคาดว่าจะรับจำนวนเต็ม และ -> float หมายถึงคาดว่าจะส่งผลลัพธ์เป็นทศนิยม

คำอธิบายเหล่านี้เรียกว่า type hints เป็นเพียงคำใบ้ ไม่ได้แปลงค่าให้อัตโนมัติ และไม่จำเป็นต่อการทำงานของฟังก์ชัน ผู้เริ่มต้นสามารถอ่านโค้ดโดยดูส่วนคำนวณเป็นหลักได้

## 9. ขอบเขตของตัวแปร

ตัวแปรที่สร้างไว้ภายในฟังก์ชันใช้ได้ภายในฟังก์ชันนั้นเป็นหลัก

~~~python
def calculate_total(price, quantity):
    total = price * quantity
    return total

result = calculate_total(100, 2)
print(result)
~~~

ตัวแปร total ถูกสร้างภายในฟังก์ชัน ส่วน result ถูกสร้างภายนอกเพื่อเก็บค่าที่ฟังก์ชันส่งกลับมา

## 10. ทำไมบางไฟล์มี if __name__ == "__main__"

ในไฟล์ตัวอย่างหรือโจทย์บางไฟล์ อาจเห็นโค้ดลักษณะนี้อยู่ท้ายไฟล์:

~~~python
if __name__ == "__main__":
    main()
~~~

รูปแบบนี้ใช้ตรวจว่าเรากำลังเปิดไฟล์นี้โดยตรงหรือมีไฟล์อื่นนำเข้าไปใช้ ถ้าเปิดไฟล์โดยตรง Python จะเรียก main() แต่ถ้าไฟล์อื่นนำเข้า ฟังก์ชัน main() จะไม่ถูกรันเอง

ผู้เรียนไม่ต้องเขียนรูปแบบนี้ในโจทย์ช่วงแรก เพียงรู้ว่ามันเป็นส่วนควบคุมการเริ่มทำงานของไฟล์

## สรุป

- def ใช้ประกาศฟังก์ชัน
- การประกาศฟังก์ชันยังไม่ทำงานจนกว่าจะเรียกใช้
- parameter คือชื่อที่รับข้อมูล และ argument คือค่าที่ส่งเข้าไป
- return ส่งค่ากลับและจบฟังก์ชัน
- print แสดงข้อความ แต่ return ส่งค่ากลับไปให้โค้ดส่วนอื่น
- พารามิเตอร์กำหนดค่าเริ่มต้นได้

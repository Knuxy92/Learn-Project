# บทที่ 17: แปลงชนิดข้อมูลและวันที่

## ทบทวน

บทที่ 16 ทำให้ข้อความสะอาดขึ้น ทั้งตัดช่องว่าง ปรับตัวพิมพ์ และรวมชื่อเรียก

แต่ข้อความที่สะอาดแล้วก็ยังเป็นข้อความอยู่

`"450"` หน้าตาสะอาดแล้ว แต่เอาไปคูณไม่ได้

บทนี้จึงแปลงข้อความให้เป็นชนิดข้อมูลที่คำนวณได้จริง

## ทำไมชนิดข้อมูลจึงสำคัญ

ตอนอ่านไฟล์ CSV ด้วย `read_csv` Pandas เดาชนิดให้จากหน้าตาของค่า

ถ้าทุกค่าในคอลัมน์ดูเป็นข้อความ มันจะเก็บทั้งคอลัมน์เป็นข้อความ

ปัญหาคือคอลัมน์ที่มีทั้งตัวเลขและค่าว่าง มักถูกอ่านเป็นทศนิยมพร้อมค่า `nan` ซึ่งใช้แทนจำนวนเต็มไม่ได้

ลองดูจำนวนสินค้า

```python
import pandas as pd

orders = pd.read_csv("data/raw/orders.csv", encoding="utf-8")
print(orders["quantity"].head(6).tolist())
print(orders["quantity"].dtype)
```

ผลลัพธ์

```txt
[2.0, 5.0, -1.0, 3.0, 0.0, nan]
float64
```

จำนวนชิ้นเป็น 2.0 ไม่ใช่ 2 เพราะมีค่าหายไปปนอยู่

ถ้าเอาไปใช้ต่อ เช่นนับจำนวนชิ้นรวม จะได้ทศนิยมที่ไม่มีทางเป็นจริง

## `pd.to_numeric` แปลงข้อความเป็นตัวเลข

`pd.to_numeric` แปลงทั้งคอลัมน์ให้เป็นตัวเลข

พารามิเตอร์ `errors="coerce"` บอกว่า ถ้าเจอค่าที่แปลงไม่ได้ ให้เปลี่ยนเป็นค่าว่างแทนที่จะโยนข้อผิดพลาด

นี่คือหัวใจของการทำความสะอาด เพราะข้อมูลจริงย่อมมีค่าที่แปลงไม่ได้ปนมาเสมอ

```python
import pandas as pd

values = pd.Series(["450", "300.00", "abc", ""])
print(pd.to_numeric(values, errors="coerce").tolist())
```

ผลลัพธ์

```txt
[450.0, 300.0, nan, nan]
```

ถ้าไม่ใส่ `errors="coerce"` ทั้งบรรทัดจะพังทันทีที่เจอ `"abc"`

## กำจัดสัญลักษณ์ก่อนแปลง

`to_numeric` แปลง `"฿1,150"` ไม่ได้ เพราะมีสัญลักษณ์เงินกับ comma คั่นหลักพัน

ต้องตัดออกก่อนด้วย `str.replace`

```python
import pandas as pd

orders = pd.read_csv("data/raw/orders.csv", encoding="utf-8")
prices = orders["unit_price"]

print(prices.head(6).tolist())
```

ผลลัพธ์

```txt
['4200.00', '฿1,150', '450', '300.00', '300', '1150.00']
```

มีทั้งเครื่องหมายบาท มี comma และมีทศนิยมปนกัน

```python
cleaned = prices.str.replace("฿", "", regex=False).str.replace(",", "", regex=False)
print(cleaned.head(6).tolist())
```

ผลลัพธ์

```txt
['4200.00', '1150', '450', '300.00', '300', '1150.00']
```

ตอนนี้ทุกค่าเป็นตัวเลขล้วน จึงแปลงได้

```python
numeric = pd.to_numeric(cleaned.str.strip(), errors="coerce")
print(numeric.head(6).tolist())
print(numeric.dtype)
```

ผลลัพธ์

```txt
[4200.0, 1150.0, 450.0, 300.0, 300.0, 1150.0]
float64
```

ทั้ง 42 แถวแปลงได้หมด ยกเว้นแถวที่ราคาว่างจริง ๆ

```python
print(int(numeric.isna().sum()))
```

ผลลัพธ์

```txt
3
```

การนับจำนวนแถวที่แปลงไม่ได้คือการตรวจสอบว่าการทำความสะอาดทำอะไรไปบ้าง ถ้าตัวเลขนี้สูงเกินคาด แปลว่ารูปแบบข้อมูลเปลี่ยนไปจากที่คิด

## จำนวนเต็มแบบมีช่องว่าง

ราคาเป็นทศนิยมได้ แต่จำนวนชิ้นต้องเป็นจำนวนเต็ม

ถ้าแปลงเป็น `int` ตรง ๆ จะพังเพราะมีค่า `nan` ปนอยู่

Pandas มีชนิดข้อมูลชื่อ `Int64` ซึ่งเป็นจำนวนเต็มที่ยอมให้มีค่าว่างได้ สังเกตตัว I ใหญ่

```python
import pandas as pd

orders = pd.read_csv("data/raw/orders.csv", encoding="utf-8")
quantity = pd.to_numeric(orders["quantity"], errors="coerce").astype("Int64")

print(quantity.head(6).tolist())
print(quantity.dtype)
```

ผลลัพธ์

```txt
[2, 5, -1, 3, 0, <NA>]
Int64
```

ค่าที่หายไปแสดงเป็น `<NA>` ซึ่งเป็นค่าว่างของชนิดนี้

ข้อดีคือค่าที่เป็นตัวเลขยังเป็นจำนวนเต็มแท้ ไม่ใช่ 2.0

## อ่านวันที่สามรูปแบบ

คอลัมน์วันที่มีสามรูปแบบปนกัน คือ `2025/02/23`, `19/03/2025` และ `2025-06-11`

`pd.to_datetime` แปลงได้ แต่มีกับดัก

```python
import pandas as pd

orders = pd.read_csv("data/raw/orders.csv", encoding="utf-8")
dates = orders["order_date"]

print(dates.head(6).tolist())
```

ผลลัพธ์

```txt
['2025/02/23', '19/03/2025', '2025-06-11', '2025-02-26', '2025/11/08', '2025-11-07']
```

รูปแบบที่ขึ้นต้นด้วยปีคือปี เดือน วัน ส่วนรูปแบบที่มี slash คั่นคือวัน เดือน ปี

ถ้าบอกให้อ่านวันก่อนเดือน (`dayfirst=True`) มันจะอ่าน `2025-06-11` ผิดเป็นวันที่ 6 พฤศจิกายน

```python
wrong = pd.to_datetime(dates, format="mixed", dayfirst=True, errors="coerce")
print(wrong.head(6).dt.strftime("%Y-%m-%d").tolist())
```

ผลลัพธ์

```txt
['2025-02-23', '2025-03-19', '2025-11-06', '2025-02-26', '2025-08-11', '2025-07-11']
```

เทียบกับค่าดิบแล้วจะเห็นว่าแถวที่ 3, 5 และ 6 ผิด เดือนกับวันสลับกัน

สาเหตุคือ `dayfirst` ถูกใช้กับทุกรูปแบบ รวมถึงรูปแบบที่ขึ้นต้นด้วยปีซึ่งไม่กำกวมเลย

วิธีแก้คือแยกสองกลุ่มออกจากกัน กลุ่มที่ขึ้นต้นด้วยปีอ่านแบบไม่ต้องเดา ส่วนที่เหลืออ่านแบบวันก่อนเดือน

```python
text = dates.astype("string").str.strip()
iso_like = text.str.match(r"^\d{4}[-/]\d{1,2}[-/]\d{1,2}$")

iso = pd.to_datetime(text.where(iso_like), format="mixed", dayfirst=False, errors="coerce")
day_first = pd.to_datetime(text.where(~iso_like), format="mixed", dayfirst=True, errors="coerce")

correct = iso.fillna(day_first)
print(correct.head(6).dt.strftime("%Y-%m-%d").tolist())
```

ผลลัพธ์

```txt
['2025-02-23', '2025-03-19', '2025-06-11', '2025-02-26', '2025-11-08', '2025-11-07']
```

`where` เก็บค่าไว้เฉพาะตำแหน่งที่เงื่อนไขเป็นจริง ตำแหน่งอื่นกลายเป็นค่าว่าง

`fillna` จึงเติมผลจากอีกกลุ่มหนึ่งเข้าไปได้พอดี

## ดึงส่วนของวันที่ออกมา

เมื่อเป็นชนิดวันที่แล้ว ตัวช่วย `dt` เปิดให้ดึงปี เดือน และวันออกมาได้

```python
print(correct.dt.year.head(3).tolist())
print(correct.dt.month.head(3).tolist())
print(correct.dt.day.head(3).tolist())
```

ผลลัพธ์

```txt
[2025, 2025, 2025]
[2, 3, 6]
[23, 19, 11]
```

## สร้างคอลัมน์เดือนสำหรับสรุปรายเดือน

งานสรุปยอดมักต้องการกลุ่มตามเดือน

`dt.strftime` แปลงวันที่เป็นข้อความตามรูปแบบที่กำหนด `%Y-%m` คือปีเต็มกับเดือนสองหลัก

การเก็บเป็นข้อความแบบนี้ทำให้เรียงลำดับได้ถูกต้อง เพราะปีมาก่อนเดือน

```python
months = correct.dt.strftime("%Y-%m")
print(months.value_counts().sort_index().to_string())
```

ผลลัพธ์

```txt
order_date
2025-01    3
2025-02    5
2025-03    4
2025-04    7
2025-05    2
2025-06    2
2025-07    4
2025-08    1
2025-10    5
2025-11    6
2025-12    3
```

สังเกตว่าเดือน 09 หายไป เพราะไม่มีออเดอร์ในเดือนนั้น การสรุปรายเดือนจึงต้องระวังว่าช่วงที่ขาดหายไม่ได้หมายถึงข้อมูลผิด

## เก็บผลลัพธ์เป็นคอลัมน์ใหม่

เมื่อได้คอลัมน์เดือนแล้ว เก็บลงตารางด้วย `assign` ซึ่งคืนตารางใหม่โดยไม่แก้ต้นฉบับ

```python
orders_with_month = orders.assign(month=months)
print(orders_with_month.groupby("month").size().to_string())
```

## สรุป

| งาน | ฟังก์ชัน | ตัวเลือกสำคัญ |
|---|---|---|
| ข้อความถึงตัวเลข | `pd.to_numeric` | `errors="coerce"` |
| ตัดสัญลักษณ์ก่อนแปลง | `str.replace` | `regex=False` เมื่อต้องการตรงตัว |
| จำนวนเต็มที่มีค่าว่าง | `.astype("Int64")` | I ใหญ่ |
| ข้อความถึงวันที่ | `pd.to_datetime` | `format="mixed"` และ `errors="coerce"` |
| วันที่กำกวม | แยกกลุ่มก่อนแปลง | วันที่ขึ้นต้นด้วยปีไม่ต้องใช้ `dayfirst` |
| ดึงส่วนของวันที่ | `.dt.year` `.dt.month` `.dt.day` | ใช้ได้เฉพาะชนิดวันที่ |
| ทำเป็นข้อความปีเดือน | `.dt.strftime("%Y-%m")` | เรียงลำดับได้ถูกต้อง |

## 1. ตัวแปรเก็บค่า

ตัวแปร (variable) คือชื่อที่ใช้เรียกค่าที่เก็บไว้ เพื่อนำมาใช้ซ้ำภายหลัง

~~~python
name = "Nattapong"
age = 17
spend = 1250.5

print(name)
print(age)
print(spend)
~~~

ผลลัพธ์:

~~~txt
Nattapong
17
1250.5
~~~

เครื่องหมาย = ในบรรทัดกำหนดตัวแปรหมายถึงนำค่าทางขวาไปเก็บไว้ในชื่อตัวแปรทางซ้าย ไม่ใช่เครื่องหมายเปรียบเทียบว่าเท่ากัน

ชื่อตัวแปรควรสื่อความหมาย เช่น customer_name, age และ unit_price ใช้ตัวอักษรภาษาอังกฤษตัวเล็ก และใช้ _ คั่นคำ

## 2. เปลี่ยนค่าของตัวแปร

ตัวแปรเดิมสามารถรับค่าใหม่ได้:

~~~python
spend = 1250.5
print(spend)

spend = spend + 250
print(spend)
~~~

ผลลัพธ์:

~~~txt
1250.5
1500.5
~~~

บรรทัด spend = spend + 250 หมายถึงนำค่าเดิมมาบวก 250 แล้วเก็บผลลัพธ์กลับเข้าไปใน spend

## 3. ชนิดข้อมูลคืออะไร

ชนิดข้อมูล (data type) บอกว่าแต่ละค่าเป็นข้อมูลประเภทใด เพราะข้อมูลแต่ละประเภททำสิ่งต่างกันได้

| ชนิด | ความหมาย | ตัวอย่าง | ใช้เก็บอะไร |
|---|---|---|---|
| int | จำนวนเต็ม | 17, 0, -5 | จำนวนชิ้น อายุ |
| float | จำนวนทศนิยม | 1250.5, 0.0 | ราคา ยอดเงิน |
| str | ข้อความ | "C001", "paid" | รหัส ชื่อ สถานะ |
| bool | ค่าจริงหรือเท็จ | True, False | สถานะที่มีสองทางเลือก |

หมายเหตุ: รหัสลูกค้ามักเก็บเป็นข้อความ แม้จะมีแต่ตัวเลข เพราะรหัสอาจมีเลขศูนย์นำหน้า เช่น "0012" และเราไม่ได้เอารหัสไปคำนวณ

## 4. ตรวจชนิดของค่า

ใช้คำสั่ง type() เพื่อตรวจชนิดของค่า:

~~~python
print(type(42))
print(type(3.5))
print(type("C001"))
print(type(True))
~~~

ผลลัพธ์:

~~~txt
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
~~~

วงเล็บหลัง type คือการส่งค่าที่ต้องการตรวจเข้าไปให้คำสั่งนี้

## 5. ข้อความกับตัวเลขไม่เหมือนกัน

แม้ "450" และ 450 จะดูคล้ายกัน แต่ตัวแรกเป็นข้อความ ส่วนตัวที่สองเป็นจำนวนเต็ม

~~~python
price_text = "450"
price_number = 450

print(type(price_text))
print(type(price_number))
~~~

ข้อความต่อกับข้อความได้:

~~~python
print("C" + "001")
~~~

ผลลัพธ์:

~~~txt
C001
~~~

แต่ข้อความบวกตัวเลขโดยตรงไม่ได้:

~~~python
# print("450" + 3)  # ถ้าเอา # ออกจะเกิด TypeError
~~~

## 6. แปลงชนิดข้อมูล

ใช้ int() แปลงเป็นจำนวนเต็ม, float() แปลงเป็นทศนิยม และ str() แปลงเป็นข้อความ

~~~python
print(int("42") + 8)
print(float("1250.50"))
print(str(2024))
~~~

ผลลัพธ์:

~~~txt
50
1250.5
2024
~~~

ข้อควรระวัง:

- int("300.00") แปลงไม่ได้ เพราะข้อความนี้มีจุดทศนิยม
- int(3.9) ได้ 3 เพราะตัดส่วนทศนิยมทิ้ง ไม่ได้ปัดเศษ
- float("abc") แปลงไม่ได้และเกิด ValueError

ถ้าข้อมูลราคาอาจมีทั้ง "450" และ "300.00" เราสามารถแปลงผ่าน float() ก่อน:

~~~python
price = int(float("300.00"))
print(price)
~~~

ผลลัพธ์:

~~~txt
300
~~~

## 7. ค่าจริงและเท็จ

bool() แปลงค่าเป็น True หรือ False

~~~python
print(bool(0))
print(bool(1))
print(bool(""))
print(bool("paid"))
~~~

ผลลัพธ์:

~~~txt
False
True
False
True
~~~

ตัวเลขศูนย์และข้อความว่างเป็น False ส่วนข้อความที่มีตัวอักษรเป็น True แม้ข้อความนั้นจะเป็น "0" ก็ตาม

## 8. None หมายถึงไม่มีค่า

None ใช้แทนกรณีที่ไม่มีค่า เช่น ยังไม่มีอีเมลของลูกค้า

~~~python
email = None

print(email)
print(email is None)
~~~

ผลลัพธ์:

~~~txt
None
True
~~~

อย่าสับสนระหว่าง 0 กับ None: ศูนย์คือค่าตัวเลขที่มีอยู่ ส่วน None หมายถึงไม่มีค่า

## 9. จัดรูปแบบตัวเลขในข้อความ

f-string ที่เรียนในบทแรกสามารถกำหนดรูปแบบตัวเลขได้

~~~python
spend = 1250.5

print(f"ยอดใช้จ่าย {spend} บาท")
print(f"ยอดใช้จ่าย {spend:.2f} บาท")
print(f"ยอดใช้จ่าย {spend:,.2f} บาท")
~~~

ผลลัพธ์:

~~~txt
ยอดใช้จ่าย 1250.5 บาท
ยอดใช้จ่าย 1250.50 บาท
ยอดใช้จ่าย 1,250.50 บาท
~~~

:.2f แสดงทศนิยมสองตำแหน่ง ส่วน :,.2f เพิ่มเครื่องหมายคั่นหลักพัน

## สรุป

- ตัวแปรใช้เก็บค่าและเรียกกลับมาใช้
- int คือจำนวนเต็ม, float คือทศนิยม, str คือข้อความ และ bool คือจริงหรือเท็จ
- type() ใช้ตรวจชนิดของค่า
- int(), float() และ str() ใช้แปลงชนิด
- 0 กับ None มีความหมายต่างกัน

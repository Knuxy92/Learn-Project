## ตัวแปรคือชื่อที่ชี้ไปยังค่า

ตัวแปร (variable) คือชื่อที่เราใช้เรียกค่าเก็บไว้ใช้ซ้ำ

ใน Python ตัวแปรไม่ใช่กล่องที่ต้องจองที่ไว้ล่วงหน้า มันเป็นเพียงชื่อที่ชี้ไปยังค่าในหน่วยความจำ เมื่อเราเขียน `spend = 1250.5` ชื่อ `spend` ก็ชี้ไปที่ตัวเลขนั้น

ทำไมเรื่องนี้สำคัญกับงานทำความสะอาดข้อมูล เพราะคอลัมน์ทุกคอลัมน์ในตารางคือค่าที่เราจะดึงออกมาใส่ตัวแปร เพื่อตรวจและแก้ทีละค่า ถ้าตั้งชื่อตัวแปรไม่ดี เราจะอ่านโค้ดของตัวเองไม่รู้เรื่องภายในสัปดาห์เดียว

```python
def demo_create_variables() -> None:
    name = "Nattapong Sri"
    age = 34
    spend = 1250.5
    is_member = True

    print(name)
    print(age)
    print(spend)
    print(is_member)
```

ผลลัพธ์

```txt
Nattapong Sri
34
1250.5
True
```

ชื่อตัวแปรใช้ภาษาอังกฤษ ตัวพิมพ์เล็ก คั่นด้วยขีดล่าง เช่น `signup_date` หรือ `unit_price` ตามชื่อคอลัมน์ในข้อมูลจริง เพื่อให้เราจับคู่โค้ดกับตารางได้ทันที

## การเปลี่ยนค่า

ตัวแปรเดิมรับค่าใหม่ได้ตลอด และชนิดของค่าก็เปลี่ยนได้ด้วย

```python
def demo_reassign() -> None:
    spend = 1250.5
    print(spend)

    spend = spend + 250
    print(spend)
```

ผลลัพธ์

```txt
1250.5
1500.5
```

บรรทัด `spend = spend + 250` ให้อ่านว่าเอาค่าเดิมของ `spend` มาบวก 250 แล้วเอาผลไปเก็บในชื่อ `spend` ทับของเดิม

งานทำความสะอาดข้อมูลใช้รูปแบบนี้ตลอด เช่น การบวกยอดรวม การต่อข้อความ และการนับจำนวนแถวที่ผ่านเงื่อนไข

## การกำหนดหลายตัวแปรในบรรทัดเดียว

เรากำหนดหลายชื่อพร้อมกันได้ ถ้าจำนวนชื่อกับจำนวนค่าตรงกัน

```python
def demo_multiple_assignment() -> None:
    name, age = "Malee Wongsakul", 28
    print(name, age)
```

ผลลัพธ์

```txt
Malee Wongsakul 28
```

## ชนิดข้อมูลพื้นฐานสี่ชนิด

ชนิดข้อมูล (data type) คือประเภทของค่า Python แยกชนิดเพราะแต่ละชนิดเก็บและคำนวณต่างกัน

สี่ชนิดที่เราจะเจอในทุกไฟล์ข้อมูลคือ

| ชนิด | ชื่อใน Python | ตัวอย่าง | ใช้กับอะไร |
|---|---|---|---|
| จำนวนเต็ม | `int` | `34`, `-1`, `0` | จำนวนชิ้น อายุ รหัส |
| ทศนิยม | `float` | `1250.5`, `0.0` | ราคา ยอดเงิน เปอร์เซ็นต์ |
| ข้อความ | `str` | `"C001"`, `"paid"` | ชื่อ อีเมล สถานะ |
| ค่าจริงเท็จ | `bool` | `True`, `False` | สถานะสมาชิก ผลตรวจเงื่อนไข |

ดูชนิดของค่าด้วย `type` แล้วอ่านชื่อชนิดด้วย `__name__`

```python
def demo_check_types() -> None:
    samples = [42, 3.5, "C001", True, None]

    for value in samples:
        print(f"{value!r} -> {type(value).__name__}")
```

ผลลัพธ์

```txt
42 -> int
3.5 -> float
'C001' -> str
True -> bool
None -> NoneType
```

`None` คือค่าที่แปลว่าไม่มีค่า ชนิดของมันชื่อ `NoneType` เราจะเจอมันเมื่ออ่านช่องว่างจากตาราง หรือเมื่อฟังก์ชันไม่คืนอะไร

ทำไมต้องรู้ชนิด เพราะข้อมูลจากไฟล์ CSV ถูกอ่านมาเป็นข้อความเสมอ ราคา `450` จะมาในรูป `"450"` ไม่ใช่ตัวเลข ถ้าเราไม่แปลงก่อน บวกเลขจะพังทันที

## ชนิดบอกว่าเราทำอะไรกับค่าได้

ชนิดเป็นตัวกำหนดว่าค่าใดใช้ตัวดำเนินการอะไรได้

ข้อความบวกข้อความได้ แต่ข้อความบวกตัวเลขไม่ได้

```python
def demo_text_concat() -> None:
    print("C" + "001")
```

ผลลัพธ์

```txt
C001
```

ถ้าเขียน `"450" + 3` Python จะโยน `TypeError` ออกมา ไม่ใช่คืน `453` ต่างจากบางภาษา

นี่คือสาเหตุที่งานทำความสะอาดข้อมูลต้องแปลงชนิดก่อนคำนวณเสมอ

## bool เป็น int ที่ถูกจำกัดค่า

`bool` ใน Python สืบทอดมาจาก `int` โดย `True` มีค่าเท่ากับ 1 และ `False` เท่ากับ 0

```python
def demo_bool_is_int() -> None:
    print(True + 1)
    print(True + True + False)
    print(isinstance(True, int))
```

ผลลัพธ์

```txt
2
2
True
```

ประโยชน์คือเรานับจำนวนแถวที่ตรงเงื่อนไขได้ด้วยการบวกค่าจริงเท็จ

ข้อควรระวังคือ `type(True).__name__` คืน `"bool"` ไม่ใช่ `"int"` เพราะ `type` มองชนิดจริงของค่า ไม่ได้มองชนิดแม่

## None คือการไม่มีค่า

`None` ใช้แทนช่องที่ไม่มีข้อมูล

```python
def demo_none() -> None:
    email = None

    print(email)
    print(type(email).__name__)
    print(email is None)
```

ผลลัพธ์

```txt
None
NoneType
True
```

งานทำความสะอาดข้อมูลต้องแยกให้ออกระหว่างค่าว่างกับค่าศูนย์ `0` คือมีค่า แต่ `None` คือไม่มีค่า การรวมสองอย่างนี้เข้าด้วยกันจะทำให้ยอดรวมผิด

การตรวจว่าเป็น `None` ให้ใช้ `is None` ไม่ใช่ `== None` เพราะ `is` ถามว่าเป็นวัตถุเดียวกันหรือไม่ ซึ่งตรงกับความหมายที่เราต้องการ

## การแปลงชนิด

การแปลงชนิด (type conversion) คือการเปลี่ยนค่าจากชนิดหนึ่งไปอีกชนิดหนึ่ง

เราใช้ฟังก์ชันชื่อเดียวกับชนิดนั้น

```python
def demo_convert() -> None:
    print(int("42") + 8)
    print(float("1250.50"))
    print(int(float("1250.50")))
    print(str(2024))
    print(int(3.9))
    print(float(7))
    print(bool(0), bool(""), bool("paid"))
```

ผลลัพธ์

```txt
50
1250.5
1250
2024
3
7.0
False False True
```

อ่านทีละบรรทัด

- `int("42")` แปลงข้อความเป็นจำนวนเต็ม
- `float("1250.50")` แปลงข้อความเป็นทศนิยม
- `int(float("1250.50"))` แปลงผ่านทศนิยมก่อน เพราะ `int("1250.50")` โยน `ValueError` ทันที
- `int(3.9)` ตัดทศนิยมทิ้ง ไม่ปัดขึ้น
- `bool(0)` กับ `bool("")` เป็น `False` เพราะเป็นค่าที่ถือว่าไม่มีอะไร

บรรทัดที่ `int(float(...))` สำคัญมากกับข้อมูลจริง ราคาใน `orders.csv` มีทั้ง `"450"` และ `"300.00"` ซึ่งมาจากช่องเดียวกัน ถ้าเราเดาชนิดผิดทั้งคอลัมน์จะพัง

## การจัดรูปแบบตัวเลขในข้อความ

f-string จัดรูปแบบตัวเลขได้ด้วยการเติมเครื่องหมายหลังจุดทวิภาค

```python
def demo_format_spend() -> None:
    spend = 1250.5

    print(f"ยอดใช้จ่าย {spend} บาท")
    print(f"ยอดใช้จ่าย {spend:.2f} บาท")
    print(f"ยอดใช้จ่าย {spend:,.2f} บาท")
```

ผลลัพธ์

```txt
ยอดใช้จ่าย 1250.5 บาท
ยอดใช้จ่าย 1250.50 บาท
ยอดใช้จ่าย 1,250.50 บาท
```

`:.2f` บังคับทศนิยมสองตำแหน่ง และ `:,.2f` เพิ่มเครื่องหมายคั่นหลักพัน

งานทำความสะอาดข้อมูลใช้สองแบบนี้ในรายงานสรุป เพื่อให้ยอดเงินอ่านง่ายและมีตำแหน่งทศนิยมเท่ากันทุกบรรทัด

## ฟังก์ชันที่บทนี้จะให้เขียน

บทนี้มีสองฟังก์ชัน

`describe_customer(name, age, spend, is_member)` รวมข้อมูลลูกค้าหนึ่งคนเป็นข้อความบรรทัดเดียว คั่นด้วยเครื่องหมายขีดตั้ง และจัดยอดใช้จ่ายเป็นทศนิยมสองตำแหน่ง

`type_report(value)` บอกชื่อชนิดของค่าที่ส่งเข้ามา

ตัวอย่างผลลัพธ์ที่ควรได้

```txt
Somchai | 34 | 1250.50 | member
Malee | 28 | 0.00 | guest
```

## สรุป

| ต้องการ | ใช้ |
|---|---|
| เก็บค่าธรรมดา | `ชื่อ = ค่า` |
| เปลี่ยนค่าเดิม | `ชื่อ = ชื่อ + ค่าใหม่` |
| ดูชนิดของค่า | `type(value).__name__` |
| ข้อความเป็นจำนวนเต็ม | `int("42")` |
| ข้อความเป็นทศนิยม | `float("1250.50")` |
| ทศนิยมเป็นจำนวนเต็ม | `int(3.9)` ได้ `3` |
| ตรวจว่าไม่มีค่า | `value is None` |
| ทศนิยมสองตำแหน่ง | `f"{spend:.2f}"` |
| คั่นหลักพัน | `f"{spend:,.2f}"` |

สามข้อที่ต้องจำ

1. ข้อมูลจาก CSV มาเป็นข้อความเสมอ ต้องแปลงก่อนคำนวณ
2. `int("300.00")` พัง ต้องผ่าน `float` ก่อน
3. `0` กับ `None` ไม่เหมือนกัน

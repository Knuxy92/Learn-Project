## นิพจน์คืออะไร

นิพจน์ (expression) คือส่วนของโค้ดที่คำนวณออกมาเป็นค่าได้หนึ่งค่า

`450 * 3` เป็นนิพจน์ ให้ค่า `1350` และ `total >= 1000` เป็นนิพจน์ ให้ค่า `True` หรือ `False`

ตัวดำเนินการ (operator) คือเครื่องหมายที่เชื่อมค่าเหล่านั้นเข้าด้วยกัน เช่น `*`, `+`, `>=`

ทำไมต้องแยกคำสองคำนี้ เพราะงานทำความสะอาดข้อมูลเกือบทั้งหมดคือการเขียนนิพจน์สั้น ๆ หลายชั้น เช่น ยอดรวมคูณกัน แล้วหักส่วนลด แล้วเทียบเกณฑ์ส่งฟรี ถ้าเราแยกได้ว่าตัวไหนคือค่า ตัวไหนคือตัวดำเนินการ เราจะแก้โค้ดผิดพลาดน้อยลง

## ตัวดำเนินการทางคณิตศาสตร์

ตัวดำเนินการคณิตศาสตร์ (arithmetic operator) ใช้คำนวณตัวเลข

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---|---|---|---|
| `+` | บวก | `450 + 3` | `453` |
| `-` | ลบ | `450 - 3` | `447` |
| `*` | คูณ | `450 * 3` | `1350` |
| `/` | หารเป็นทศนิยม | `7 / 2` | `3.5` |
| `//` | หารตัดเศษ | `7 // 2` | `3` |
| `%` | เศษจากการหาร | `7 % 2` | `1` |
| `**` | ยกกำลัง | `2 ** 10` | `1024` |

```python
def demo_arithmetic() -> None:
    print(450 * 3)
    print(7 / 2)
    print(7 // 2)
    print(7 % 2)
    print(2**10)
```

ผลลัพธ์

```txt
1350
3.5
3
1
1024
```

ข้อสังเกตที่สำคัญที่สุดคือ `/` คืน `float` เสมอ แม้หารลงตัว

ในงานข้อมูล เราใช้ `//` น้อย แต่ใช้ `%` บ่อย เช่น แบ่งข้อมูลเป็นกลุ่มตามลำดับ หรือตรวจว่าเลขคู่หรือเลขคี่

## ลำดับความสำคัญของตัวดำเนินการ

ลำดับความสำคัญ (precedence) คือกติกาที่บอกว่าตัวดำเนินการใดทำก่อน

คูณกับหารทำก่อนบวกกับลบ และวงเล็บทำก่อนทุกอย่าง

```python
def demo_precedence() -> None:
    print(450 + 3 * 100)
    print((450 + 3) * 100)
```

ผลลัพธ์

```txt
750
45300
```

ผลต่างกันราวหกสิบเท่า มาจากวงเล็บคู่เดียว

นิสัยที่ดีคือใส่วงเล็บเมื่อกำกวม แม้จะไม่จำเป็นก็ตาม เพราะคนอ่านโค้ดจะไม่ต้องจำตารางลำดับความสำคัญ

## ตัวดำเนินการกำหนดค่าแบบผสม

ตัวดำเนินการกำหนดค่าแบบผสม (augmented assignment) คือการเขียนย่อของการคำนวณแล้วเก็บทับ

```python
def demo_augmented() -> None:
    total = 1000.0

    total -= 100
    print(total)
```

ผลลัพธ์

```txt
900.0
```

`total -= 100` มีความหมายเดียวกับ `total = total - 100`

ใช้ได้กับ `+=`, `-=`, `*=`, `/=` ทั้งหมด งานทำความสะอาดข้อมูลใช้ `+=` บ่อยเมื่อสะสมยอดรวมในลูป

## ปัญหาทศนิยม

`float` เก็บค่าได้ไม่แม่นยำทุกกรณี เพราะหน่วยความจำมีจำกัด

```python
def demo_float_precision() -> None:
    print(0.1 + 0.2)
    print(round(0.1 + 0.2, 2))
```

ผลลัพธ์

```txt
0.30000000000000004
0.3
```

ถ้าเราเขียน `0.1 + 0.2 == 0.3` จะได้ `False`

นี่คือสาเหตุที่งานการเงินไม่ควรเทียบทศนิยมด้วย `==` ตรง ๆ ให้ใช้ `round` ก่อน หรือยอมรับความต่างเล็กน้อยด้วยการเทียบช่วง

ในบทนี้เราจะใช้ `round` และการจัดรูปแบบทศนิยมสองตำแหน่งเป็นหลัก ซึ่งเพียงพอสำหรับงานทำความสะอาดข้อมูลระดับนี้

## ตัวดำเนินการกับข้อความ

`+` ต่อข้อความสองอันเข้าด้วยกัน และ `*` ทำข้อความซ้ำ

```python
def demo_string_operators() -> None:
    print("C" + "001")
    print("-" * 10)
```

ผลลัพธ์

```txt
C001
----------
```

การต่อข้อความใช้สร้างรหัสหรือชื่อคอลัมน์ใหม่ เช่น ต่อ `C` กับเลขลำดับ

แต่ระวัง ข้อความบวกตัวเลขไม่ได้ Python จะโยน `TypeError` ถ้าต้องการต่อ ให้แปลงตัวเลขเป็นข้อความด้วย `str` ก่อน

## ตัวดำเนินการเปรียบเทียบ

ตัวดำเนินการเปรียบเทียบ (comparison operator) ให้ผลเป็น `True` หรือ `False`

| เครื่องหมาย | ความหมาย |
|---|---|
| `==` | เท่ากันหรือไม่ |
| `!=` | ไม่เท่ากันหรือไม่ |
| `>` | มากกว่า |
| `<` | น้อยกว่า |
| `>=` | มากกว่าหรือเท่ากัน |
| `<=` | น้อยกว่าหรือเท่ากัน |

```python
def demo_comparisons() -> None:
    print(450 > 300)
    print(450 == 450.0)
    print("paid" == "PAID")
    print("paid" == "paid ")
    print("paid".strip() == "paid")
```

ผลลัพธ์

```txt
True
True
False
False
True
```

สามบรรทัดที่เทียบข้อความคือหัวใจของงานทำความสะอาดข้อมูล

`450 == 450.0` เป็นจริงเพราะ Python เทียบค่าตัวเลข ไม่ได้เทียบชนิด

แต่ `"paid" == "PAID"` เป็นเท็จ และ `"paid" == "paid "` ก็เป็นเท็จ เพราะการเทียบข้อความสนใจตัวพิมพ์และช่องว่างทุกตัว

นี่คือเหตุผลที่ข้อมูลสถานะใน `orders.csv` ที่มีทั้ง `paid`, `PAID` และ `Paid ` ต้องถูกทำความสะอาดก่อนนับ ยอดนับจะได้ไม่แตกเป็นหลายกลุ่ม

## การเปรียบเทียบแบบต่อเนื่อง

Python อนุญาตให้เขียนการเปรียบเทียบต่อกันได้ในนิพจน์เดียว

```python
def demo_chained_comparison() -> None:
    print(500 <= 500 < 1000)
```

ผลลัพธ์

```txt
True
```

นิพจน์นี้หมายถึง `500 <= 500` และ `500 < 1000` ต้องเป็นจริงทั้งคู่

ใช้ตรวจช่วงข้อมูล เช่น ยอดที่อยู่ระหว่างสองเกณฑ์ โดยไม่ต้องเขียน `and` สองรอบ

## ตัวดำเนินการตรรกะ

ตัวดำเนินการตรรกะ (logical operator) ใช้รวมเงื่อนไข

| เครื่องหมาย | ความหมาย | เป็นจริงเมื่อ |
|---|---|---|
| `and` | และ | จริงทั้งสองข้าง |
| `or` | หรือ | จริงอย่างน้อยหนึ่งข้าง |
| `not` | ไม่ | กลับค่าจริงเท็จ |

```python
def demo_boolean_operators() -> None:
    print(True and False)
    print(True or False)
    print(not True)
```

ผลลัพธ์

```txt
False
True
False
```

ใช้รวมเงื่อนไขกรองข้อมูล เช่น เอาเฉพาะออเดอร์ที่ชำระแล้วและยอดถึงเกณฑ์

## ความจริงเท็จของค่า

ใน Python ทุกค่าใช้เป็นเงื่อนไขได้ ค่าที่ถือว่าเท็จมีไม่กี่อย่าง ที่เหลือถือว่าจริง

```python
def demo_truthiness() -> None:
    print(bool(0), bool(-1), bool(""), bool("0"))
```

ผลลัพธ์

```txt
False True False True
```

อ่านให้ดี `0` เป็นเท็จ แต่ `-1` เป็นจริง เพราะตัวเลขใดที่ไม่ใช่ศูนย์ถือว่าจริง

และ `"0"` เป็นจริง เพราะเป็นข้อความที่ไม่ว่าง

นี่คือกับดักที่พบบ่อยมาก ข้อมูลที่อ่านจาก CSV เป็นข้อความ `"0"` จึงเป็นจริงเสมอ ถ้าเราเขียน `if quantity:` โดยไม่แปลงชนิดก่อน แถวที่จำนวนเป็นศูนย์จะถูกนับว่ามีของ

## การตรวจค่า None

`None` คือการไม่มีค่า และต้องตรวจด้วย `is` ไม่ใช่ `==`

```python
def demo_none_check() -> None:
    tier = None

    print(tier is None)
```

ผลลัพธ์

```txt
True
```

ใช้ `is None` และ `is not None` เป็นมาตรฐาน เพราะ `is` ถามว่าเป็นวัตถุเดียวกันหรือไม่ ซึ่งตรงกับความหมายของการไม่มีค่าอย่างแท้จริง

## สรุป

| ต้องการ | ใช้ |
|---|---|
| บวก ลบ คูณ | `+`, `-`, `*` |
| หารเอาเศษทศนิยม | `/` |
| หารตัดเศษ | `//` |
| เศษจากการหาร | `%` |
| ยกกำลัง | `**` |
| เทียบค่า | `==`, `!=` |
| เทียบช่วง | `500 <= x < 1000` |
| รวมเงื่อนไข | `and`, `or`, `not` |
| ตรวจไม่มีค่า | `is None` |
| ปัดทศนิยม | `round(value, 2)` |

สามข้อที่ต้องจำ

1. `/` คืนทศนิยมเสมอ และทศนิยมเทียบด้วย `==` ไม่น่าเชื่อถือ
2. การเทียบข้อความสนใจตัวพิมพ์และช่องว่าง ต้องทำความสะอาดก่อน
3. `"0"` เป็นจริง ส่วน `0` เป็นเท็จ ต้องแปลงชนิดให้ถูกก่อนใช้เป็นเงื่อนไข

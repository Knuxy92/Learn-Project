## 1. ตัวดำเนินการทางคณิตศาสตร์

ตัวดำเนินการ (operator) คือเครื่องหมายที่ใช้ทำงานกับค่า เช่น บวก ลบ และคูณ

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---|---|---|---|
| + | บวก | 450 + 3 | 453 |
| - | ลบ | 450 - 3 | 447 |
| * | คูณ | 450 * 3 | 1350 |
| / | หาร | 7 / 2 | 3.5 |
| // | หารเอาจำนวนเต็ม | 7 // 2 | 3 |
| % | เศษจากการหาร | 7 % 2 | 1 |
| ** | ยกกำลัง | 2 ** 3 | 8 |

~~~python
price = 450
quantity = 3

total = price * quantity
print(total)
print(7 / 2)
print(7 // 2)
print(7 % 2)
~~~

ผลลัพธ์:

~~~txt
1350
3.5
3
1
~~~

เครื่องหมาย / ให้ผลลัพธ์เป็นทศนิยม ส่วน // ตัดเศษทิ้ง

## 2. ลำดับการคำนวณ

Python คูณและหารก่อนบวกและลบ ส่วนวงเล็บจะถูกคำนวณก่อน

~~~python
print(450 + 3 * 100)
print((450 + 3) * 100)
~~~

ผลลัพธ์:

~~~txt
750
45300
~~~

ใส่วงเล็บเมื่ออยากให้ลำดับการคำนวณชัดเจน แม้บางครั้งจะไม่จำเป็นก็ตาม

## 3. การคำนวณแล้วเก็บค่ากลับ

เครื่องหมาย += และ -= เป็นรูปแบบย่อของการคำนวณแล้วเก็บผลกลับเข้าไปในตัวแปรเดิม

~~~python
total = 1000
total = total - 100
print(total)

total = 1000
total -= 100
print(total)
~~~

ผลลัพธ์:

~~~txt
900
900
~~~

ทั้งสองวิธีให้ผลเหมือนกัน

## 4. ปัญหาความแม่นยำของทศนิยม

คอมพิวเตอร์ไม่สามารถแทนค่าทศนิยมบางค่าได้ตรงเป๊ะทุกครั้ง

~~~python
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
~~~

ผลลัพธ์:

~~~txt
0.30000000000000004
0.3
~~~

round(value, 2) ใช้ปัดค่าให้เหลือทศนิยมสองตำแหน่ง ในงานการเงินจริงอาจต้องใช้ decimal แต่ในหลักสูตรนี้จะใช้ round เพื่ออธิบายแนวคิดพื้นฐาน

## 5. ตัวดำเนินการเปรียบเทียบ

ตัวดำเนินการเปรียบเทียบให้ผลเป็น True หรือ False

| เครื่องหมาย | ความหมาย |
|---|---|
| == | เท่ากันหรือไม่ |
| != | ไม่เท่ากันหรือไม่ |
| > | มากกว่า |
| < | น้อยกว่า |
| >= | มากกว่าหรือเท่ากัน |
| <= | น้อยกว่าหรือเท่ากัน |

~~~python
print(450 > 300)
print(450 == 450)
print(450 != 300)
print(500 <= 500)
~~~

ผลลัพธ์:

~~~txt
True
True
True
True
~~~

ระวัง: = ใช้กำหนดค่าให้ตัวแปร ส่วน == ใช้เปรียบเทียบว่าสองค่าเท่ากันหรือไม่

## 6. เปรียบเทียบข้อความ

การเปรียบเทียบข้อความสนใจตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก และช่องว่าง

~~~python
print("paid" == "PAID")
print("paid" == "paid ")
print("paid" == "paid")
~~~

ผลลัพธ์:

~~~txt
False
False
True
~~~

ข้อมูลจริงอาจมีสถานะเป็น paid, PAID หรือ paid ตามด้วยช่องว่าง เราจะเรียนวิธีจัดการช่องว่างและตัวพิมพ์ในบทที่ 7

## 7. เปรียบเทียบเป็นช่วง

Python สามารถเขียนเปรียบเทียบต่อกันได้

~~~python
score = 75
print(50 <= score < 80)
~~~

ผลลัพธ์:

~~~txt
True
~~~

อ่านว่า score ต้องมากกว่าหรือเท่ากับ 50 และน้อยกว่า 80

## 8. ตัวดำเนินการตรรกะ

ใช้ and, or และ not เพื่อรวมเงื่อนไข

| คำสั่ง | ความหมาย |
|---|---|
| and | จริงเมื่อทั้งสองเงื่อนไขจริง |
| or | จริงเมื่อมีอย่างน้อยหนึ่งเงื่อนไขจริง |
| not | กลับค่าจริงเป็นเท็จ หรือเท็จเป็นจริง |

~~~python
print(True and False)
print(True or False)
print(not True)
~~~

ผลลัพธ์:

~~~txt
False
True
False
~~~

## 9. สรุป

- +, -, *, / ใช้คำนวณพื้นฐาน
- // ใช้หารเอาจำนวนเต็ม และ % ใช้หาเศษ
- == ใช้เปรียบเทียบ ส่วน = ใช้กำหนดค่า
- and, or และ not ใช้รวมเงื่อนไข
- ข้อความที่ต่างกันแม้เพียงช่องว่างหรือตัวพิมพ์ก็ถือว่าไม่เท่ากัน

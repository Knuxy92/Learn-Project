# Agent Loop: เว็บอ่านบทเรียน Astro 5 (pnpm) — ทำจนจบ + validate ตัวเอง

## โหมดทำงาน (ตามสั่ง)

ทำแบบอัตโนมัติเต็มระบบ จบเมื่องานเสร็จ + validate ครบทุกข้อ รายงานกระชับ (caveman style ภาษาไทย) **หยุดทันทีเมื่อติด blocker ที่แก้เองไม่ได้** (เช่น ไม่มี Node/pnpm, build พังซ่อนไม่ได้ 3 รอบ) — ทิ้งสถานะให้กลับมาต่อได้ (git checkpoint สุดท้าย) แล้วรอคำสั่ง

**Package manager: pnpm (สุดท้ายแล้ว ตามสั่ง)** — ล็อกด้วย `packageManager` field ใน package.json + `pnpm-lock.yaml` commit ทุกครั้ง

**Skills ที่ใช้ตลอด loop** (โหลดแล้ว): `subagent-fanout` (**cap 5 ตัว/รอบ — concurrency ต่ำ ยัดงานหนักต่อตัว + วิ่งหลายรอบ, บอกจำนวนก่อนยิงทุกครั้ง**) · `git-checkpoint` (commit หลังทุก logical unit — สัมผัสเฉพาะไฟล์งานนี้สร้าง/แก้ เว้น modified files เดิมของ repo) · `zero-trust` (ตัวเลขที่รายงานต้องนับ/วัดจริง, ติด label Verified/Unverified) · `caveman` (รายงานไม่เล่าพิธี) · `hallmark` (audit หน้า build จริง 58 gates) · `write-thai` (UI copy ไทยที่เพิ่มเองให้เป็นธรรมชาติ ไม่ขัด Design.md)

ข้อเท็จจริง repo (Verified): ไม่มี Node tooling; Ch1–5 เฟนซ์ `~~~` / Ch6 ผสม / Ch7–21 backticks; จับคู่ผลลัพธ์จากบรรทัด "ผลลัพธ์" (270 บล็อก); 18/21 บทมี table (โปรโตไทป์ยังไม่มีสไตล์ตาราง)

## ขั้นตอน (แต่ละขั้นจบ → git checkpoint)

**P0 preflight** — `node --version` (≥18.17), `pnpm --version` (ไม่มี → ลอง `corepack enable` ก่อน ยังไม่ได้อีก = STOP)

**P1 scaffold `web/`** — package.json (astro@5, @fontsource/ibm-plex-sans-thai, @fontsource/jetbrains-mono, lucide-static + `packageManager: "pnpm@..."`), astro.config.mjs (static), tsconfig → `pnpm install` → build ว่างผ่าน

**P2 pipeline** — `content.config.ts` glob loader อ่าน `../curriculum/*.md` · `rehype-code-pairs.mjs` (จับคู่ code+"ผลลัพธ์" → `.pair.tight`) · `rehype-sections.mjs` (h2→section id, ทบทวน/สรุป→การ์ด, โจทย์→`ul.tasks` ช่องติ๊ก) · `data/chapters.ts` manifest 5 กลุ่ม + นับโค้ดตอน build · Shiki ธีมสีเดียว (kw=accent/str=ink-2/com=ink-3 ผ่าน CSS vars)

**P3 หน้าเว็บ** — `styles/app.css` พอร์ตโปรโตไทป์ 1:1 + สไตล์ `<table>` (หัวตาราง paper-3, ไร้เส้นขอบ, มือถือ scroll แนวนอน) · `index.astro` (Index-First + "อ่านค้างไว้ที่บทที่ N") · `chapters/[id].astro` (Long Document: topbar, readbar, TOC scroll-spy, prev/next) · components PillNav/Toc/Icon (inline SVG จาก lucide-static self-host) · scripts site.ts/copy.ts/progress.ts (`lp:teaching` default "1" / `lp:last` / `lp:done:{chNN}`)

**P4 build loop** — `pnpm build` ซ่อนจนผ่าน (แต่ละ fix = 1 checkpoint)

**P5 validate ด้วย fanout — cap 5 ตัว/รอบ วิ่ง 2 รอบ:**
- **รอบ 1 (5 ตัว)**: แบ่ง 21 บท ≈ 4–5 บท/ตัว (ch01–05 · ch06–09 · ch10–13 · ch14–17 · ch18–21) ตัวละตรวจหนัก: จำนวน figure.result ตรง txt block จริงทุกบทในชุด, ป้ายภาษา, การ์ด/ช่องติ๊ก/ตาราง render ถูก, รายงาน per-chapter pass/fail พร้อมหลักฐาน
- **รอบ 2 (3 ตัว)**: (1) Hallmark audit index + 1 บท (58 gates) (2) mobile/contrast gates 320–768px (gate 34/40/49) (3) localStorage behavior ผ่าน reload จริง
- fail → แก้เอง → re-check → checkpoint; แก้ไม่ได้ 3 รอบ → STOP รายงาน

**P6 hosting + ปิดงาน** — Dockerfile (corepack/pnpm build → caddy:alpine เสิร์ฟ dist) + `web/README.md` ไทยตาม write-thai + .gitignore เพิ่ม web/node_modules, web/dist, web/.astro

**P7 รายงานจบ** — สิ่งที่สร้าง · ผล validate ทุกตัว (เฉพาะ Verified) · checkpoint list · สิ่งค้างเฟส 2 (ค้นหา, Pyodide)

# เรียน Python สู่การทำความสะอาดข้อมูล

โปรเจกต์นี้พาผู้เรียนเริ่มจากการใช้คอมพิวเตอร์รัน Python ไปจนถึงการทำความสะอาดข้อมูลด้วย NumPy และ Pandas โดยสมมติว่าผู้เรียนไม่เคยเขียนโปรแกรมมาก่อน

หลักสูตรหยุดที่ระดับ **ข้อมูลพร้อมใช้** ไม่ลงลึกถึงโมเดลหรือแมชชีนเลิร์นนิง

## สภาพแวดล้อมที่ใช้

หลักสูตรนี้ใช้ **Windows 10/11 และ Command Prompt (CMD)** เป็นสภาพแวดล้อมหลัก คำสั่งในบทเรียนเขียนสำหรับ CMD ไม่ใช่ PowerShell, Git Bash หรือ Linux

สิ่งที่ต้องติดตั้ง:
- Python 3.11 ขึ้นไป
- Git for Windows
- โปรแกรมแก้ไขโค้ด เช่น Visual Studio Code

## เริ่มต้นใช้งาน

### 1. ติดตั้ง Python

ดาวน์โหลด Python จาก https://www.python.org/downloads/windows/

ระหว่างติดตั้ง ให้เลือก **Add python.exe to PATH** ก่อนกดติดตั้ง หากมีตัวเลือก Python Launcher ให้ติดตั้งไว้ด้วย PATH คือรายการตำแหน่งที่ Windows ใช้ค้นหาโปรแกรม เมื่อเลือกตัวเลือกนี้ CMD จะหาคำสั่ง Python เจอโดยไม่ต้องพิมพ์ตำแหน่งไฟล์เต็ม

เปิด Command Prompt โดยกดปุ่ม Windows พิมพ์ cmd แล้วกด Enter จากนั้นตรวจสอบ:

~~~cmd
py --version
~~~

ควรเห็นเวอร์ชัน Python 3.11 หรือใหม่กว่า

### 2. ดาวน์โหลดโปรเจกต์

Git clone คือการดาวน์โหลดสำเนาโปรเจกต์จาก GitHub มาไว้ในเครื่อง พร้อมข้อมูลเวอร์ชันของ Git ใน CMD ให้ไปยัง Desktop แล้ว Clone โปรเจกต์:

~~~cmd
cd /d "%USERPROFILE%\Desktop"
git clone --branch starting-python-datasci --single-branch https://github.com/Knuxy92/Learn-Project.git
cd Learn-Project
~~~

ถ้าโฟลเดอร์ Learn-Project มีอยู่แล้ว ให้เข้าโฟลเดอร์นั้นแทนการ Clone ซ้ำ:

~~~cmd
cd /d "%USERPROFILE%\Desktop\Learn-Project"
~~~

### 3. สร้างพื้นที่ติดตั้งไลบรารีของโปรเจกต์

Virtual Environment คือพื้นที่แยกสำหรับติดตั้งไลบรารีของโปรเจกต์นี้ ไม่ไปรบกวน Python ของงานอื่น

~~~cmd
py -m venv .venv
.venv\Scripts\activate.bat
~~~

เมื่อเปิดใช้งานสำเร็จ จะเห็น (.venv) อยู่หน้าบรรทัดคำสั่ง

ติดตั้งไลบรารีที่ใช้ในหลักสูตร:

~~~cmd
python -m pip install --upgrade pip
python -m pip install "numpy>=2.0,<3" "pandas>=3.0,<4" "pytest>=8.0,<10" "ruff>=0.6,<1"
~~~

ต้องเปิดใช้งาน Virtual Environment ใหม่ทุกครั้งที่เปิด CMD หน้าต่างใหม่ โดยเข้าโฟลเดอร์โปรเจกต์แล้วสั่ง:

~~~cmd
.venv\Scripts\activate.bat
~~~

### 4. เปิดโปรเจกต์และรันโค้ดแรก

เปิดโฟลเดอร์ Learn-Project ด้วยโปรแกรมแก้ไขโค้ด จากนั้นกลับมาที่ CMD ซึ่งอยู่ในโฟลเดอร์โปรเจกต์และรัน:

~~~cmd
python curriculum\ch01\hello-world.py
~~~

ถ้าเห็นข้อความ Hello Data แสดงว่า Python รันไฟล์ได้แล้ว

## คำสั่งที่ใช้บ่อย

คำสั่งทั้งหมดต่อไปนี้ใช้ใน CMD จากโฟลเดอร์หลักของโปรเจกต์ และต้องเปิดใช้งาน Virtual Environment ก่อน

รันตัวอย่าง:

~~~cmd
python curriculum\ch01\hello-world.py
~~~

รันการทดสอบทั้งหมด:

~~~cmd
python -m pytest
~~~

รันการทดสอบเฉพาะบท:

~~~cmd
python -m pytest tests\test_ch05.py
~~~

ตรวจรูปแบบโค้ด:

~~~cmd
python -m ruff check .
~~~

สร้างข้อมูลดิบใหม่:

~~~cmd
python data\make_dataset.py
~~~

## ข้อมูลที่ใช้เรียน

ทุกบทใช้ชุดข้อมูลเดียวกันใน data/raw/ ซึ่งตั้งใจให้มีปัญหาเพื่อให้ได้ฝึกทำความสะอาดข้อมูลจริง

- customers.csv มีรหัสซ้ำ ชื่อมีช่องว่าง อีเมลตัวพิมพ์ปน ประเทศสะกดหลายแบบ และวันที่สามรูปแบบ
- products.csv ชื่อสินค้าและหมวดหมู่ใช้ตัวพิมพ์ไม่สม่ำเสมอ
- orders.csv มีแถวซ้ำ ค่าว่าง ราคาติดลบ และรหัสลูกค้าที่ไม่มีอยู่จริง
- customers_th.csv เป็นไฟล์ภาษาไทยที่บันทึกพร้อม BOM

## ข้อตกลงของโปรเจกต์

- ใช้ Python 3.11 ขึ้นไป
- ใช้ CMD เป็นคำสั่งหลักในบทเรียน
- ตั้งชื่อตัวแปรและฟังก์ชันเป็นภาษาอังกฤษ ข้อความที่ผู้ใช้เห็นเป็นภาษาไทย
- ตัวอย่างช่วงแรกเขียนจากบนลงล่างโดยตรง ยังไม่ใช้ฟังก์ชันจนกว่าจะถึง Ch5
- ฟังก์ชันคืนค่า ไม่พิมพ์ข้างใน ยกเว้นส่วนสาธิตที่ระบุไว้
- เปิดไฟล์โดยระบุ encoding="utf-8" ทุกครั้ง
- ตัวอย่างทุกไฟล์รันจบได้เอง ไม่ค้างรอ input

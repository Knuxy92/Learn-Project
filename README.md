## Current Track

เริ่มใหม่ตาม curriculum:

1. JavaScript Fundamentals
2. JavaScript Intermediate
3. TypeScript
4. Building APIs

ไฟล์หลัก:

- `CURRICULUM_TRACK.md`
- `CHAPTER_STATUS.md`
- `curriculum/ch01-setup-first-code.md`
- `exercises/ch01-first-code.js`

## Start Here

อ่านบทแรก:

```bash

```

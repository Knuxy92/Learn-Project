บทที่ 01 / 21 · 17 ชุดโค้ด

ติดตั้ง Python และรันโค้ดแรก

บทนี้เริ่มจากศูนย์ เป้าหมายไม่ใช่เขียนโปรแกรมเก่งทันที แต่คือทำให้เปิด CMD เข้าโฟลเดอร์โปรเจกต์ เปิดไฟล์ Python และสั่งให้คอมพิวเตอร์ทำงานได้ด้วยตัวเอง

1. Python คืออะไร

Python คือภาษาโปรแกรม เราเขียนคำสั่งด้วยภาษาที่คนอ่านได้ แล้วให้โปรแกรม Python แปลคำสั่งเหล่านั้นเป็นการทำงานของคอมพิวเตอร์

หลักสูตรนี้ใช้ Python เพราะมีเครื่องมือสำหรับจัดการข้อมูล เช่น NumPy และ Pandas

2. เตรียมโปรแกรมที่ต้องใช้

หลักสูตรนี้ใช้ Windows 10/11 และ Command Prompt (CMD) ติดตั้งโปรแกรมต่อไปนี้ก่อนเริ่ม

  1. Python 3.11 ขึ้นไป ตอนติดตั้งให้เลือก Add python.exe to PATH
  2. Git for Windows
  3. Visual Studio Code หรือโปรแกรมแก้ไขโค้ดที่ถนัด

PATH คือรายการตำแหน่งที่ Windows ใช้ค้นหาโปรแกรม เมื่อเลือกตัวเลือกนี้ CMD จะหาคำสั่ง Python เจอโดยไม่ต้องพิมพ์ตำแหน่งไฟล์เต็ม

3. เปิด CMD

กดปุ่ม Windows พิมพ์ cmd แล้วกด Enter หน้าต่างที่เปิดขึ้นมาคือ Command Prompt ตรวจสอบว่า Python พร้อมใช้งานหรือยัง

ตัวเลขเวอร์ชันอาจต่างกันได้ ขอให้เป็น 3.11 หรือใหม่กว่า ถ้าขึ้นว่าไม่รู้จักคำสั่ง py ให้ตรวจว่าติดตั้ง Python Launcher แล้วหรือยัง

4. เขียนคำสั่งแรกด้วย print

เปิด Visual Studio Code เลือก File > Open Folder แล้วสร้างไฟล์ใหม่ชื่อ hello.py ตรวจให้แน่ใจว่านามสกุลเป็น .py ไม่ใช่ .txt พิมพ์โค้ดนี้แล้วกด Ctrl+S เพื่อบันทึก

กลับไปที่ CMD แล้วสั่ง python hello.py ถ้าเห็นข้อความนี้ แปลว่าเราเขียนไฟล์ Python และสั่งให้ Python รันไฟล์ได้แล้ว

5. รู้จักตัวแปร

ตัวแปร (variable) คือชื่อที่ใช้เก็บค่าไว้เรียกใช้ภายหลัง

บรรทัด student_name = "Student" หมายถึงเก็บข้อความ Student ไว้ภายใต้ชื่อ student_name ส่วน print ใช้แสดงค่าที่เก็บไว้

6. แสดงข้อความร่วมกับตัวแปร

f-string ช่วยแทรกค่าของตัวแปรลงในข้อความ โดยใส่ตัวอักษร f ไว้หน้าข้อความ และใส่ชื่อตัวแปรไว้ในวงเล็บปีกกา

บันทึกไฟล์ แล้วรันด้วย CMD: python exercises\ch01-first-code.py

ถ้าเจอปัญหา

  • py is not recognized — ติดตั้ง Python Launcher หรือแก้ PATH แล้วเปิด CMD ใหม่
  • python is not recognized — ตรวจการตั้งค่า PATH ของ Python หรือลองใช้ py แทนได้
  • can't open file — ตรวจว่า CMD อยู่ในโฟลเดอร์ Learn-Project ด้วยคำสั่ง dir
  • No module named ... — ตรวจว่าเปิดใช้งาน .venv แล้วติดตั้งไลบรารีครบ

สรุป

  • Python คือภาษาที่เราใช้เขียนคำสั่งให้คอมพิวเตอร์ทำงาน
  • CMD ใช้พิมพ์คำสั่งเพื่อเข้าโฟลเดอร์และรันไฟล์
  • ไฟล์ Python ลงท้ายด้วย .py
  • print ใช้แสดงผล ตัวแปรใช้เก็บค่า f-string ใช้แทรกค่าตัวแปรในข้อความ
